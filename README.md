# macbeth

タブレット完結型 3D モデリング・スカルプト・テクスチャリングアプリケーションの設計ドキュメント。

Maya のポリゴン編集精度、ZBrush のスカルプト、Substance Painter のテクスチャリングを、iPad / Android タブレット上でペンと指のみで扱えるようにすることを目指します。PC（Windows / macOS）でも同一コードベースで動作させます。

## 現在の状態

**設計フェーズ。** 実装はまだ始まっていません。

**実装方針（改訂）: v1.0 はモデリング特化で、Web（TypeScript + WebGL2 / WebGPU）で構築します。** スカルプト版に向けてジオメトリカーネルは C++ で書いて wasm に載せ、必要になればそのカーネルをネイティブに持ち出します。経緯と判断は `docs/09-direction-review.md`。ネイティブ C++ の設計（`docs/02-architecture.md`）はその段階の参照として残しています。

## プロトタイプ

[`prototype/modeling-ui-prototype.html`](prototype/modeling-ui-prototype.html) — 操作感の検証用。ブラウザで開くだけで動きます。

**タブレットで開く:** GitHub の Settings → Pages で Branch をこのブランチ、Folder を `/ (root)` にすると、`https://nekohachi.github.io/macbethUnity/` で単体ページとして開けます（ログイン不要、ホーム画面に追加で全画面）。ルートの `index.html` はその単体ページで、`prototype/make-pages.sh` で生成します。プロトタイプを編集したら再生成してください。

v1.0 が Web 基盤に確定したので、このプロトタイプは使い捨てではなく**製品の種**です。ただし単一 HTML のままでは製品構造にならないため、次の実装作業は機能追加ではなく TypeScript + モジュール分割 + テストへの再構成です（`docs/09-direction-review.md` の「次の実装依頼」）。

**方針: まず Maya のクローンとして作り、そこから UI をタブレットに寄せる。**

実装済み:

- **マーキングメニューは 8 方位固定。** 選択モードは Maya のポリゴン用と同じ配置（北=エッジ、北東=オブジェクトモード、東=UV、南東=マルチ、南=フェース、南西=頂点フェース、西=頂点、北西=空き）。どのツールを使っていても現在の選択モードを上書きする
- 呼び出しは PC が右クリック、タブレットはビューポート長押し
- **F ボタンは押しながらの修飾。** タップで選択をフレーム、押しながらドラッグで矩形選択（指でも）、押しながらピンチで選択中心を固定したズーム
- **Shift + 右クリック（PC）/ SHF + 長押し（タブレット）で編集メニュー。** 選択モードごとに内容が変わる。動くもの: 面＝押し出し／削除／コラプス／スムース、エッジ＝押し出し／エッジループ挿入／削除（面の結合）、頂点＝マージ、オブジェクト＝スムース／複製／削除。ベベルやブリッジ等は位置だけ確保
- **Shift + 移動で押し出し。** 面またはエッジを選んで SHF を押しながらマニピュレータを動かすと、押し出してから移動する
- **マルチカットは予測線つき。** ホバー（またはタップ中）で挿入されるループを黄色で表示し、離した位置で確定。Shift で 50% 固定、オプションにステップ % スナップ、スムージング角度、エッジフロー（頂点法線による三次補間でループをサーフェスに沿わせる）
- **スムース**（Catmull-Clark）を実装。ディバイドの土台になる
- スムージング角度で法線を分ける（Maya のソフト / ハードエッジに相当）。「シェード」表示はすべてハード
- ビューポート左下に指操作用クラスタ。上段 SHF / F、下段 CTL / ALT、4 つとも同じ大きさ
- **指 2 本ダブルタップで戻る、3 本で進む。** タップは「120ms 以内に全部着地、12px 動かない、300ms 以内に全部離れる」で判定し、2 本指のパン / ズームは 10px のデッドゾーンを越えた時点で確定するので両者は排他
- 左レールは**縦ゲージ 2 本**と Undo / Redo。ゲージはモードで中身が置き換わる（モデリング＝ソフト選択の強度と範囲、スカルプト＝ブラシ強度とサイズ、マテリアル＝不透明度とサイズ）
- ソフト選択は実際に効く。周囲の頂点が減衰しながら追従し、影響範囲をオレンジで表示
- ツールにカメラ設定（焦点距離、アングルオブビュー、ニア／ファークリップ、平行投影）とシェーディング切替を追加。カメラ設定は他をタップすると閉じる
- シェーディングは長押しでサークルメニュー。ワイヤーフレーム / シェード / シェード + ワイヤー / スムースシェード（キーボードは 4–7）
- オプションパネルは選択中のツールとオブジェクトで内容が変わる
- アウトライナはダブルタップで名前変更、長押しでサークルメニュー
- 選択色を Maya に合わせた。オブジェクト＝グリーン、コンポーネント＝オレンジ、未選択頂点＝パープル
- 8 種の非破壊プリミティブ。すべて原点に生成
- 矩形選択、マニピュレータ（ロケーター／移動／回転／スケール）、マルチカット、面の押し出し
- PC のカメラは Maya 準拠。`Alt+左` タンブル / `Alt+中` パン / `Alt+右` ドリー、選択モードは `F8`–`F11`
