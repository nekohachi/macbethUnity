# macbeth

タブレット完結型 3D モデリング・スカルプト・テクスチャリングアプリケーションの設計ドキュメント。

Maya のポリゴン編集精度、ZBrush のスカルプト、Substance Painter のテクスチャリングを、iPad / Android タブレット上でペンと指のみで扱えるようにすることを目指します。PC（Windows / macOS）でも同一コードベースで動作させます。

## 現在の状態

**設計フェーズ。** 実装はまだ始まっていません。

**実装方針は決定済み: ゲームエンジンを使わず、ネイティブ C++ で構築します。** 理由は `docs/02-architecture.md` の 2.1 節。残る未決事項は `docs/07-roadmap.md` の 7.8 節にまとめてあります。

## プロトタイプ

[`prototype/modeling-ui-prototype.html`](prototype/modeling-ui-prototype.html) — 操作感の検証用。ブラウザで開くだけで動きます（iPad の Safari でそのまま試せます）。

製品実装はネイティブ C++ ですが、サークルメニュー、ドッキング、ジェスチャ、非破壊プリミティブは**触ってみないと良し悪しが判断できない**ため、Web で先に作って操作を固めます。ここで確定した挙動を C++ に持ち込む前提の使い捨てです。設計ドキュメントで「UI フレームワークの自作に 6〜8 週間」と見積もったリスクの前倒し検証にあたります。

**方針: まず Maya のクローンとして作り、そこから UI をタブレットに寄せる。**

実装済み:

- モードはヘッダの「モデリング ▼」1 ボタン。長押しまたは右クリックでサークルメニューを開き、UV / スカルプト / マテリアルへ切り替える
- サークルメニューは全項目にアイコンを表示。長押し 200ms、方向で仮選択、離して決定、中心 28px はキャンセル、フリックで即決定
- 左端はアイコンのみの細い縦列（幅 52px）
- 8 種の非破壊プリミティブ。Maya と同じく**すべて原点に生成**
- 矩形選択（マーキー）。オブジェクトは頂点が矩形内、エッジは中点、面は面心で判定。Shift で追加、Ctrl で除外
- マニピュレータ。選択ツールではロケーター（ピボット）、移動は 3 軸矢印 + 中心、回転は 3 軸リング + カメラ面リング、スケールは 3 軸ボックス。スクリーン一定サイズ
- PC のカメラは Maya 準拠。`Alt+左` タンブル / `Alt+中` パン / `Alt+右` ドリー / ホイール ドリー
- 右クリック（PC）と長押し（タブレット）で選択モードのマーキングメニュー
- パネルのドッキング、Undo / Redo、修飾キーのラッチ、マルチカット、面の押し出し

## 要点

- **差別化の核はマルチ解像度ブリッジ。** 高精細スカルプトの形状を保ったまま、低ポリゴンを Maya 相当のツールで編集できる。競合が持っていない機能なので、ここに集中する
- **ペン＝ツール、指＝カメラ。** この役割分離が快適な操作の前提になる
- **`.mb` と Substance のファイル形式は読めない。** それぞれ `.ma` 経由、テクスチャ書き出し経由で代替する。詳細は `06-file-formats.md`
- **`.usd` を最優先で追加すべき。** 細分割とクリースをネイティブに表現できる唯一の主要形式で、本アプリのワークフローと完全に一致する
- **v1.0 はスカルプト＋モデリング＋マルチ解像度に絞る。** マテリアルモードは v2.0
- **`core/` をプラットフォーム非依存・グラフィックス非依存に保つ。** ここが最大の資産で、検証もテストもデスクトップ上で完結できる
