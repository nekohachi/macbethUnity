# macbeth

タブレット完結型 3D モデリング・スカルプト・テクスチャリングアプリケーションの設計ドキュメント。

Maya のポリゴン編集精度、ZBrush のスカルプト、Substance Painter のテクスチャリングを、iPad / Android タブレット上でペンと指のみで扱えるようにすることを目指します。PC（Windows / macOS）でも同一コードベースで動作させます。

## 要点

- **差別化の核はマルチ解像度ブリッジ。** 高精細スカルプトの形状を保ったまま、低ポリゴンを Maya 相当のツールで編集できる。競合が持っていない機能なので、ここに集中する
- **ペン＝ツール、指＝カメラ。** この役割分離が快適な操作の前提になる
- **`.mb` と Substance のファイル形式は読めない。** それぞれ `.ma` 経由、テクスチャ書き出し経由で代替する。詳細は `06-file-formats.md`
- **`.usd` を最優先で追加すべき。** 細分割とクリースをネイティブに表現できる唯一の主要形式で、本アプリのワークフローと完全に一致する
- **v1.0 はスカルプト＋モデリング＋マルチ解像度に絞る。** マテリアルモードは v2.0
