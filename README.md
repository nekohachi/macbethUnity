# macbeth

タブレット完結型 3D モデリング・スカルプト・テクスチャリングアプリケーションの設計ドキュメント。

Maya のポリゴン編集精度、ZBrush のスカルプト、Substance Painter のテクスチャリングを、iPad / Android タブレット上でペンと指のみで扱えるようにすることを目指します。PC（Windows / macOS）でも同一コードベースで動作させます。

## 現在の状態

**土台の実装フェーズ。** ジオメトリコア（`src/core/`）、`.mbz` 形式、アプリ本体（`src/app/`）ができました。テスト 138 件に加えて、実際の Chromium で描画から選択・取り消し・自動保存まで通す確認（`npm run smoke`）が通ります。残りの機能はプロトタイプから順に移植中です（`docs/12-roadmap-v2.md`）。

アプリが入口になりました。`https://nekohachi.github.io/macbethUnity/` を開くとアプリに転送されます。プロトタイプは操作感を見比べるための参考として残してあります。

**実装方針: v1.0 はモデリング特化で、Web（TypeScript + WebGL2 / WebGPU）で構築します。** スカルプト版に向けてジオメトリカーネルは C++ で書いて wasm に載せ、必要になればそのカーネルをネイティブに持ち出します。経緯と判断は `docs/09-direction-review.md`。ネイティブ C++ の設計（`docs/02-architecture.md`）はその段階の参照として残しています。

## 開発

```
npm install
npm run dev        # 開発サーバー。入口は web/index.html（ルート /）
npm test           # core のテスト（138 件）
npm run typecheck
npm run build
npm run smoke      # ビルド後、実際のブラウザで通し確認（要 npm run build）
```

`src/core/` は **DOM にも Three.js にも依存しません**（`docs/02`、`docs/09`）。v1.5 でこの層を C++ → wasm に差し替えるときの境界なので、この境界を越えないでください。

| 場所 | 内容 |
|---|---|
| `src/core/mesh.ts` | CSR 形式のメッシュ。UV セット、クリース、ポリグループ、マテリアル ID を持つ |
| `src/core/primitives.ts` | 8 種のプリミティブ（UV 付き、原点生成） |
| `src/core/topology.ts` | エッジループ挿入、押し出し、溶接、エッジ削除。すべて UV を持ち越す |
| `src/core/selection.ts` | エッジループ / リング、シェル、拡張と縮小 |
| `src/core/subdivide.ts` | Catmull-Clark（UV とクリースも細分割。頂点点の規則にも折り目が効く）。`SubdivPlan` は動いた頂点の周りだけ計算し直せる |
| `src/core/bevel.ts` | ベベル（面取り / 丸め）。四角形メッシュ向け |
| `src/core/bridge.ts` | ブリッジ。境界エッジの 2 列を面で繋ぐ |
| `src/core/vertexOps.ts` | 距離でマージ、頂点の削除（まわりを 1 面に）、頂点の押し出し（尖らせる） |
| `src/core/connect.ts` | 接続。頂点どうし、またはエッジの中点どうしを結んで面を分ける |
| `src/core/objectOps.ts` | 面の複製 / 抽出、結合、分離、ミラー |
| `src/core/uv/` | UV。切れ目から島を作り、LSCM で開く。**レシピから再計算する非破壊の層**（`docs/15`） |
| `src/core/multires.ts` | マルチ解像度スタック。接空間デルタ（docs/03）。ベースの編集は差分更新 |
| `src/core/document.ts` | シーンの層構造（`docs/11`） |
| `src/core/io/` | OBJ、メッシュのバイナリ、`.mbz`、トポロジハッシュ |

`src/app/` はブラウザ側。ここだけが DOM と Three.js を触ります。

| 場所 | 内容 |
|---|---|
| `web/index.html` | 入口の HTML（Vite の root）。`src/app/main.ts` を読み込む |

| `src/app/input/gestures.ts` | ペンと指の割り振り。しきい値は実機で確かめた値 |
| `src/app/tools/select.ts` | Maya 準拠の選択（ループ、リング、シェル、矩形） |
| `src/app/tools/transform.ts` | 移動・回転・スケールのドラッグ |
| `src/app/tools/multicut.ts` | エッジループ挿入（予測線つき） |
| `src/app/tools/softSelect.ts` | ソフト選択の減衰と対称編集 |
| `src/app/storage/` | IndexedDB、自動保存、ファイルの読み書き |
| `src/app/uv/` | UV モードの 2D ビュー、選択と 3D との同期、カット / ソー / ピン |
| `src/app/ui/` | マーキングメニュー、ゲージ、HUD、パネル、ドッキング、縦横レイアウト、予定表、アイコン |

### 最初の 1 回だけ必要な設定

このリポジトリは **GitHub Pages がまだ有効になっていません**（ワークフローのログに
`Get Pages site: Not Found` が出ます）。サイトの新規作成だけは管理者権限が要るため
ワークフローからは有効化できません（`Resource not accessible by integration`）。

<https://github.com/nekohachi/macbethUnity/settings/pages> を開いて:

- **Source** … `Deploy from a branch`
- **Branch** … `claude/tablet-3d-modeling-app-f6b1x5` / `/ (root)`
- **Save**

これで上の URL が開くようになります。以後の更新は自動です。

`app/` はビルド済みのものです。**push のたびに `.github/workflows/publish.yml` が
自動でビルドし直して書き戻す**ので、設定はこの 1 回だけで、あとは触りません。
出す前に実際の Chromium で通し確認を走らせ、落ちたらコミットしません。

手元で先に `sh scripts/publish.sh` を実行して `app/` ごとコミットしておけば、
ワークフローは差分なしで何もしません（余計なコミットが増えない）。

Pages の Source を「GitHub Actions」にしたい場合は、`pages.yml` の `on:` を
`push:` に戻せば、ブランチに `app/` を置く必要はなくなります。ただしその場合は
`github-pages` 環境の許可ブランチに、既定ブランチ以外もを足す必要があります。

**方針: まず Maya のクローンとして作り、そこから UI をタブレットに寄せる。**

実装済み:

- **マーキングメニューは 8 方位固定。** 選択モードは Maya のポリゴン用と同じ配置（北=エッジ、北東=オブジェクトモード、東=UV、南東=マルチ、南=フェース、南西=頂点フェース、西=頂点、北西=空き）。どのツールを使っていても現在の選択モードを上書きする
- 呼び出しは PC が右クリック、タブレットはビューポート長押し
- **F ボタンは押しながらの修飾。** タップで選択をフレーム、押しながらドラッグで矩形選択（指でも）、押しながらピンチで選択中心を固定したズーム
- **Shift + 右クリック（PC）/ SHF + 長押し（タブレット）で編集メニュー。** 選択モードごとに内容が変わる。動くもの: 面＝押し出し／削除／コラプス／スムース、エッジ＝押し出し／エッジループ挿入／削除（面の結合）、頂点＝マージ、オブジェクト＝スムース／複製／削除。ベベルやブリッジ等は位置だけ確保
- **Shift + 移動で押し出し。** 面またはエッジを選んで SHF を押しながらマニピュレータを動かすと、押し出してから移動する
- **マルチカットは予測線つき。** ホバー（またはタップ中）で挿入されるループを黄色で表示し、離した位置で確定。Shift で 50% 固定、オプションにステップ % スナップ、スムージング角度、エッジフロー（頂点法線による三次補間でループをサーフェスに沿わせる）
- **スムース**（Catmull-Clark）を実装。ディバイドの土台になる
- スムージング角度で法線を分ける（Maya のソフト / ハードエッジに相当）。「シェード」表示はすべてハード
- ビューポート左下に指操作用クラスタ。上段 SHF / F、下段 CTL / ALT、4 つとも同じ大きさ
- **長押しでサークルメニュー。** 指 1 本＝マーキングメニュー、指 2 本＝選択があれば編集 / 無ければカメラ、**指 3 本＝カメラ（いつでも）**。カメラはパース / 上 / 下 / 前 / 後 / 左 / 右で Maya と同じ種類（パース以外は平行投影）。北東の「新規カメラ」で今の視点に名前を付けて控えられ、輪の下の一覧から呼び戻せる
- **指 3 本で選択を直接動かす。** マニピュレータを触らずに、選んでいる面 / エッジ / 頂点 / オブジェクトを。**つまむ**＝拡大縮小（基点は選択の中心で、そこは動かない）、**上下スワイプ**＝ワールド Y に沿って移動、**左右スワイプ**＝ X か Z に沿って移動（今見ているカメラの右方向に近い方）。どれか 1 つに決まったら離すまで入れ替わらないので、斜めに動かしても混ざらない。回転はしない。ソフト選択と対称 X はそのまま効く
- **指 2 本ダブルタップで戻る、3 本で進む。** タップは「120ms 以内に全部着地、12px 動かない、300ms 以内に全部離れる」で判定し、2 本指のパン / ズームは 10px のデッドゾーンを越えた時点で確定するので両者は排他
- 左レールは**縦ゲージ 2 本**と Undo / Redo。ゲージはモードで中身が置き換わる（モデリング＝ソフト選択の強度と範囲、スカルプト＝ブラシ強度とサイズ、マテリアル＝不透明度とサイズ）
- ソフト選択は実際に効く。周囲の頂点が減衰しながら追従し、影響範囲をオレンジで表示
- ツールにカメラ設定（焦点距離、アングルオブビュー、ニア／ファークリップ、平行投影）とシェーディング切替を追加。カメラ設定は他をタップすると閉じる
- シェーディングは長押しでサークルメニュー。ワイヤーフレーム / シェード / シェード + ワイヤー / スムースシェード（キーボードは 4–7）
- オプションパネルは選択中のツールとオブジェクトで内容が変わる
- アウトライナはダブルタップで名前変更、長押しでサークルメニュー
- 選択色を Maya に合わせた。オブジェクト＝グリーン、コンポーネント＝オレンジ、未選択頂点＝パープル
- 8 種の非破壊プリミティブ。すべて原点に生成
- **ユニバーサルマニピュレータ。** 矢印（移動）・リング（回転）・箱（スケール）を一体表示。ツールは「選択・変形」1 つで、長押しで単独モード（Q・T = 全部、W / E / R = 単独）
- **ピボットは Maya と同じ。** オブジェクト = トランスフォームの原点、コンポーネント = 選択のバウンディングボックス中心
- **選択即編集。** 選択があればマニピュレータが常に出る。選択中のコンポーネントを直接ドラッグするとビュー平面で移動（ツイーク）
- **対称編集 X（ローカル）。** 移動・回転・スケール・ソフト選択のすべてで相手側が鏡映に追従
- **OBJ 読み込み / 書き出し**（ヘッダの「ファイル ▼」）。iPad では共有シートからファイル App へ保存
- **自動保存。** 操作のたびに端末のブラウザ内へ保存し、次回開いたときに復元
- 中心にピボット、トランスフォームのフリーズ（オブジェクトの編集メニュー）
- **UV モード（C1）。** 2D と 3D を並べて、選択は面の単位で同期します。UV は「切れ目・ピン・ソルバー」のレシピから毎回計算し直す**非破壊**の作りで、手で動かした分は島ごとの差分として残ります。切れ目を 1 本変えても、変わっていない島の手直しは消えません。カット / ソー / ピン / 展開、島の移動と反転・90° 回転、指 3 本のつまみと U / V スワイプ。表示切替に「チェッカー」（`8`）が増えました
- **面の複製 / 抽出、結合 / 分離、ミラー、数値入力。** 複製は切り離した写しをその場に置き（そのまま動かせます）、抽出は選んだ面を別オブジェクトにします。結合はオブジェクトモードで **SHF を足して 2 つ以上選んでから**（座標は焼き込まれます）、分離は繋がっていない塊ごとに分けます。ミラーは軸で折り返して境目を溶接。数値入力はオプションパネルの「トランスフォーム」に移動 / 回転（度）/ スケールを直接打てます
- **スナップ。** CTL ラッチ中、または `X`（グリッド）/ `V`（頂点）/ `C`（エッジ）を押している間だけ効きます。Maya と同じ割り当てです。移動のときだけ働き、寄せ先は緑で光ります。軸ドラッグ中は軸から外れません。グリッドの刻みはオプションパネル。**対称編集のキーは `X` から `S` に移しました**（`X` を Maya のグリッドスナップに譲ったため）
- **接続。** 同じ面にある頂点どうし（頂点モード南東）、または選んだエッジの中点どうし（エッジモード西）を結んで面を分けます。隣り合う 2 点は結びません
- **頂点の編集メニュー。** 距離でマージ（しきい値はオプション）、削除（まわりの面を 1 枚に）、押し出し（法線方向へ尖らせる。SHF + ドラッグでも同じことができ、そのまま引っぱれる）
- **ダブルクリック選択は Maya と同じ。** エッジ＝ループ、フェース／頂点＝シェル。Shift + ダブルクリックで部分ループ、部分リング、フェースループ、頂点列。Ctrl で除外
- 矩形選択、マルチカット、面の押し出し
- PC のカメラは Maya 準拠。`Alt+左` タンブル / `Alt+中` パン / `Alt+右` ドリー、選択モードは `F8`–`F11`、スナップは `X` / `V` / `C`
