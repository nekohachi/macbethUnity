# macbeth

タブレット完結型 3D モデリング・スカルプト・テクスチャリングアプリケーションの設計ドキュメント。

Maya のポリゴン編集精度、ZBrush のスカルプト、Substance Painter のテクスチャリングを、iPad / Android タブレット上でペンと指のみで扱えるようにすることを目指します。PC（Windows / macOS）でも同一コードベースで動作させます。

## 現在の状態

**土台の実装フェーズ。** ジオメトリコア（`src/core/`）、`.mbz` 形式、UI シェルの土台（`src/app/`）ができました。テスト 55 件に加えて、実際の Chromium で描画から選択・取り消し・自動保存まで通す確認（`npm run smoke`）が通ります。残りの機能はプロトタイプから順に移植中です（`docs/10-next-phase.md`）。

新しいシェルは `/app.html`、ページのトップは移植が済むまで従来どおりプロトタイプです。

**実装方針: v1.0 はモデリング特化で、Web（TypeScript + WebGL2 / WebGPU）で構築します。** スカルプト版に向けてジオメトリカーネルは C++ で書いて wasm に載せ、必要になればそのカーネルをネイティブに持ち出します。経緯と判断は `docs/09-direction-review.md`。ネイティブ C++ の設計（`docs/02-architecture.md`）はその段階の参照として残しています。

## 開発

```
npm install
npm run dev        # 開発サーバー。新しいシェルは /app.html
npm test           # core のテスト（55 件）
npm run typecheck
npm run build
npm run smoke      # ビルド後、実際のブラウザで通し確認（要 npm run build）
```

`src/core/` は **DOM にも Three.js にも依存しません**（`docs/02`、`docs/09`）。v1.5 でこの層を C++ → wasm に差し替えるときの境界なので、この境界を越えないでください。

| 場所 | 内容 |
|---|---|
| `src/core/mesh.ts` | CSR 形式のメッシュ。UV セット、クリース、ポリグループ、マテリアル ID を持つ |
| `src/core/primitives.ts` | 8 種のプリミティブ（UV 付き、原点生成） |
| `src/core/topology.ts` | エッジループ挿入、押し出し、溶接、エッジ削除。すべて UV を持ち越す |
| `src/core/selection.ts` | エッジループ / リング、シェル、拡張と縮小 |
| `src/core/subdivide.ts` | Catmull-Clark（UV とクリースも細分割） |
| `src/core/document.ts` | シーンの層構造（`docs/11`） |
| `src/core/io/` | OBJ、メッシュのバイナリ、`.mbz`、トポロジハッシュ |

`src/app/` はブラウザ側。ここだけが DOM と Three.js を触ります。

| 場所 | 内容 |
|---|---|
| `src/app/state.ts` | モード、選択、修飾キー、ゲージの定義 |
| `src/app/history.ts` | 元に戻す / やり直す（シーンのスナップショット） |
| `src/app/render/` | Three.js への変換、ビューポート、ピッキング |
| `src/app/input/gestures.ts` | ペンと指の割り振り。しきい値は実機で確かめた値 |
| `src/app/tools/select.ts` | Maya 準拠の選択（ループ、リング、シェル、矩形） |
| `src/app/storage/` | IndexedDB、自動保存、ファイルの読み書き |
| `src/app/ui/` | マーキングメニュー、ゲージ、HUD、アイコン |

## タブレットで開く

| URL | 中身 |
|---|---|
| `https://nekohachi.github.io/macbethUnity/` | プロトタイプ（これまでどおり） |
| `https://nekohachi.github.io/macbethUnity/app/` | **新しいシェル。**ホーム画面に追加すると全画面・オフラインで動きます |

`app/` はビルド済みのものです。**push のたびに `.github/workflows/publish.yml` が
自動でビルドし直して書き戻す**ので、Pages の設定は今のまま（Deploy from a branch）で
最新が出ます。出す前に実際の Chromium で通し確認を走らせ、落ちたらコミットしません。

手元で先に `sh scripts/publish.sh` を実行して `app/` ごとコミットしておけば、
ワークフローは差分なしで何もしません（余計なコミットが増えない）。

Pages の Source を「GitHub Actions」に切り替えたい場合は、`pages.yml` の
`on:` を `push:` に戻せば、ブランチに `app/` を置く必要はなくなります。

**タブレットで開く（プロトタイプ）:** GitHub の Settings → Pages で Branch をこのブランチ、Folder を `/ (root)` にすると、`https://nekohachi.github.io/macbethUnity/` で開けます（ログイン不要、ホーム画面に追加で全画面）。

**方針: まず Maya のクローンとして作り、そこから UI をタブレットに寄せる。**

実装済み:

- **マーキングメニューは 8 方位固定。** 選択モードは Maya のポリゴン用と同じ配置（北=エッジ、北東=オブジェクトモード、東=UV、南東=マルチ、南=フェース、南西=頂点フェース、西=頂点、北西=空き）。どのツールを使っていても現在の選択モードを上書きする
- 呼び出しは PC が右クリック、タブレットはビューポート長押し
- **F ボタンは押しながらの修飾。** タップで選択をフレーム、押しながらドラッグで矩形選択（指でも）、押しながらピンチで選択中心を固定したズーム
- **Shift + 右クリック（PC）/ SHF + 長押し（タブレット）で編集メニュー。** 選択モードごとに内容が変わる。動くもの: 面＝押し出し／削除／コラプス／スムース、エッジ＝押し出し／エッジループ挿入／削除（面の結合）、頂点＝マージ、オブジェクト＝スムース／複製／削除。ベベルやブリッジ等は位置だけ確保
- **Shift + 移動で押し出し。** 面またはエッジを選んで SHF を押しながらマニピュレータを動かすと、押し出してから移動する
- **マルチカットは予測線つき。** ホバー（またはタップ中）で挿入されるループを黄色で表示し、離した位置で確定。Shift で 50% 固定、オプションにステップ % スナップ、スムージング角度、エッジフロー（頂点法線による三次補間でループをサーフェスに沿わせる）
- **スムース**（Catmull-Clark）を実装。ディバイドの土台になる
- スムージング角度で法線を分ける（Maya のソフト / ハードエッジに相当）。「シェード」表示はすべてハード
- ビューポート左下に指操作用クラスタ。上段 SHF / F、下段 CTL / ALT、4 つとも同じ大きさ
- **指 2 本ダブルタップで戻る、3 本で進む。** タップは「120ms 以内に全部着地、12px 動かない、300ms 以内に全部離れる」で判定し、2 本指のパン / ズームは 10px のデッドゾーンを越えた時点で確定するので両者は排他
- 左レールは**縦ゲージ 2 本**と Undo / Redo。ゲージはモードで中身が置き換わる（モデリング＝ソフト選択の強度と範囲、スカルプト＝ブラシ強度とサイズ、マテリアル＝不透明度とサイズ）
- ソフト選択は実際に効く。周囲の頂点が減衰しながら追従し、影響範囲をオレンジで表示
- ツールにカメラ設定（焦点距離、アングルオブビュー、ニア／ファークリップ、平行投影）とシェーディング切替を追加。カメラ設定は他をタップすると閉じる
- シェーディングは長押しでサークルメニュー。ワイヤーフレーム / シェード / シェード + ワイヤー / スムースシェード（キーボードは 4–7）
- オプションパネルは選択中のツールとオブジェクトで内容が変わる
- アウトライナはダブルタップで名前変更、長押しでサークルメニュー
- 選択色を Maya に合わせた。オブジェクト＝グリーン、コンポーネント＝オレンジ、未選択頂点＝パープル
- 8 種の非破壊プリミティブ。すべて原点に生成
- **ユニバーサルマニピュレータ。** 矢印（移動）・リング（回転）・箱（スケール）を一体表示。ツールは「選択・変形」1 つで、長押しで単独モード（Q・T = 全部、W / E / R = 単独）
- **ピボットは Maya と同じ。** オブジェクト = トランスフォームの原点、コンポーネント = 選択のバウンディングボックス中心
- **選択即編集。** 選択があればマニピュレータが常に出る。選択中のコンポーネントを直接ドラッグするとビュー平面で移動（ツイーク）
- **対称編集 X（ローカル）。** 移動・回転・スケール・ソフト選択のすべてで相手側が鏡映に追従
- **OBJ 読み込み / 書き出し**（ヘッダの「ファイル ▼」）。iPad では共有シートからファイル App へ保存
- **自動保存。** 操作のたびに端末のブラウザ内へ保存し、次回開いたときに復元
- 中心にピボット、トランスフォームのフリーズ（オブジェクトの編集メニュー）
- **ダブルクリック選択は Maya と同じ。** エッジ＝ループ、フェース／頂点＝シェル。Shift + ダブルクリックで部分ループ、部分リング、フェースループ、頂点列。Ctrl で除外
- 矩形選択、マルチカット、面の押し出し
- PC のカメラは Maya 準拠。`Alt+左` タンブル / `Alt+中` パン / `Alt+右` ドリー、選択モードは `F8`–`F11`
