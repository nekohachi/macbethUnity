## T1. ローをハイに合わせる

### 考え

段 1 の**頂点点**はレベル 0 の頂点と 1 対 1（Catmull-Clark の並びは
頂点点 → エッジ点 → 面点。`32` で確かめた）。だから

```
低 ← 低 + (ハイの段 1 の頂点点 − 細分割(低) の頂点点) × relax
```

を数回まわせば、**細分割した結果がハイにいちばん近づくローの形**が出る。

**ハイの形は 1 ミリも動かさない。** 先に各段のメッシュを控え、ローを動かしたあとで
`sculpt(i, 控え_i)` を段の下から順に当て直す。デルタだけが小さくなる。

### 決め

- `Multires.fitBaseToDetail(iterations = 8)` を core に置く（`subdivide` を持っているのはここ）
- `relax = 1`。行の和が 1 の作用素なので 1 なら必ず縮む。8 回で残差は 1 桁下がる
- 戻り値は `{ residual, before, after }`（残差と、デルタの最大の長さの前後）。**報告に書く**
- 段が無ければ何もしない
- **境界と折り目は `catmullClark` に任せる**（自前で頂点点の式を書かない。規則が
  2 か所に分かれると必ずずれる）

### つなぐ

段のボタンの長押し（`levelItems`）に「**ローをハイに合わせる**」。履歴は 1 段
（レベル 0 の座標 + 全部のデルタが変わるので、丸ごとの控え）。

### テスト

- 球の段 2 を大きく彫ってから合わせる: **ハイの座標が変わらない**（1e-6 以下）、
  **デルタの最大が小さくなる**、レベル 0 が動く
- 段が無ければ何も起きない
- 2 回続けて呼んでも 2 回目はほとんど動かない（収束している）

## T2. 再投影

### 考え

`markTopologyChanged` は上位レベルを捨てる。**捨てる直前のいちばん上のメッシュを
控える**（`SceneObject.detailCache`）。ユーザーが段を割り直したあと、
「ハイを戻す」で**今の段の頂点を、控えのメッシュのいちばん近い所へ動かす**。

### 決め

- 控えは `{ mesh, level }`。`.mbz` には**入れない**（作業中の都合。開き直せば無い）
- 近い所は **`trianglesNear` で拾ってから三角形上の最近点**。光線は飛ばさない
  （法線方向に飛ばすと、へこみで刺さらない。最近点なら必ず当たる）
- 探す半径は**そのメッシュの平均辺長 × 2**から始めて、当たらなければ 2 倍を 3 回まで
- 動かしたら `sculpt(level, projected)` でデルタに焼く
- 控えは 1 つだけ持つ（トポロジを 2 回変えたら 2 回目で上書き）

### つなぐ

段のボタンの長押しに「**ハイを戻す（再投影）**」。控えが無ければ薄くして押せない。

### テスト

- 球の段 2 を彫る → 控えを取る → レベル 0 を編集（トポロジを変える）→ 段を割り直す →
  再投影すると、**彫った形が戻る**（控えとの距離が平均で辺長の 1 割以下）
- 控えが無ければ `null` を返して何もしない

## T3. スカルプトレイヤー

### 考え

段ごとに「デルタ + 重み」を何枚も持つ。**その段の効いているデルタ**は

```
total = base + Σ (見えているレイヤー.delta × 重み)
```

`base` は今までの `multires[i].delta`（レイヤーを使わない人はここだけ）。

### 記録

`state.activeLayer` が入っていて、その段が今の段なら、**彫った分はそのレイヤーへ**。
`sculptAt` は座標から `total` を取り直すので、

```
レイヤー.delta += (新しい total − 今の total) ÷ 重み
```

で切り分ける。重み 0 のレイヤーには記録しない（0 で割ることになる）。

### 決め

- レイヤーは**段ごと**（`SculptLayer.level`）。段を変えたら、その段のレイヤーだけ出す
- 重みは 0〜2（ZBrush の Layer は 0〜1 だが、強調に使えるので上を伸ばす）
- 「統合」でベースへ足して 1 枚に畳む
- `.mbz` に入れる（形式の版を上げる）
- 履歴: レイヤーの追加・削除・統合は丸ごとの控え。彫った分は今までどおりの差分

### つなぐ

ツール列に「レイヤー」のボタン。カットインに一覧（見える / 名前 / 重み / 記録中）と
追加・削除・統合。

### テスト

- 2 枚に分けて彫ると、重み 0 で片方が消える / 1 で戻る
- 重み 0.5 で**ちょうど半分**
- 統合すると 1 枚になり、形は変わらない
- `.mbz` の往復で残る

## 報告（2026-09-10。T1〜T4 済）

### T1: ローをハイに合わせる

`Multires.fitBaseToDetail(iterations = 8, relax = 1.6)`。

**`28` の書き方だけでは効かなかった。** 「レベル 0 を段 1 に合わせる」だけだと、
段 2 で彫ったときに段 1 には何も乗っていない（`level(1) === 細分割(レベル 0)`）ので、
**合わせる先がすでに一致していて 1 ミリも動かない**。テストで最初に落ちたのがこれ。

**いちばん上から順に下ろす**ように直した。段 L の形を目当てに段 L−1 を寄せ、
それを段 L−2 の目当てにする。守るのは**いちばん上の形だけ**で、途中の段は
「上に近い滑らかな面」に置き直す。だからどの段のデルタも小さくなる。

| 直し | 理由 |
|---|---|
| `relax = 1.6` | 1 では詰まるのが遅い。行の和が 1 の作用素なので 2 未満なら縮む |
| **上の段ほど回す数を減らす**（`iterations >> (level − 1)`、下限 3） | 細分割は段が上がるごとに 4 倍重い。途中の段はそこまで詰めなくてよい |
| 合わせ直しを **`rebuild` と同じ道の 1 周**に | `sculpt` を段の数だけ呼ぶと、そのたびに控えを捨てて全段を組み直す。25 万で **3836ms → 1836ms** |

### T2: 再投影

- `core/reproject.ts`: `projectOnto`（最近点。`trianglesNear` で拾って三角形上の最近点）と
  `averageEdge`。光線は飛ばさない（へこみで刺さらずに抜ける）
- `SceneObject.detailCache`: `markTopologyChanged` が**捨てる直前に**いちばん上の段を控える。
  `.mbz` にも履歴にも入れない
- 探す半径は平均辺長 × 2 から始めて 2 倍を 3 回まで。`maxDist`（辺長 × 32）より遠ければ
  **動かさない**（大きくトポロジを変えたときに見当違いの所へ吸い付かないため）
- 段のボタンの長押しに「ハイを戻す（再投影）」。控えが無ければ出ない

### T3: スカルプトレイヤー

効いているデルタ = `素のデルタ + Σ(見えているレイヤー × 重み)`。

| 決め | 中身 |
|---|---|
| **レイヤーが 1 枚も無い段は、今までと同じ道** | `levelsOf` が `multires` の配列を**そのまま**渡す。合成の配列を作らないので、使わない人に掛かりが増えない |
| 記録先 | `state.activeLayer`。段が違う / 重み 0 / 非表示なら**素のデルタへ落とす**（0 で割らない） |
| 切り分け | `sculptAt` が書くのは合成のほう。**流すたびに、触った頂点だけ**差を記録先へ入れる（`(合成の増分) ÷ 重み`）。`base + Σ w·L` は常に合成と一致する |
| 履歴 | `SculptDiff.layer` に**書き込んだ先**を持つ。戻すときも同じ所へ書き、合成を取り直してから形にする |
| `.mbz` | もともと `sculptLayers` を読み書きしていた（形式の版は上げていない） |
| UI | ツール列に「レイヤー」。カットインに一覧（記録先・表示・重み・削除）と 追加 / 統合 |
