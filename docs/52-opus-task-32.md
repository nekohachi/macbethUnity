## T1. 変形の長押しにマージを入れる

### 何が起きていたか

マージは `45` の T3 で**変形の輪の下の一覧**へ置いた。ところが一覧を作る
`manipulatorItems()` は先頭で

```ts
if (this.state.compMode !== "vertex") return [];
```

と切っている。**オブジェクトモードや面モードで長押しすると一覧が空**になり、
輪の 8 区画にもマージは無い。つまり「頂点モードに入ってから長押しする」を
知っている人にしか出せなかった。実機ではまず出せない。

### 決め

- 輪の **NW**（左上）を「**距離でマージ**」にする。8 方位のどこかに無いと、
  「長押ししてマージ」がそもそも見えない
  - そこに居た「初期設定に戻す」は**一覧へ降ろす**（めったに使わない）
- `manipulatorItems()` は**モードで切らない**。中身は
  「中心にマージ」と「初期設定に戻す」の 2 行
- `doMergeByDistance()` は**頂点モードでなければ、頂点モードへ入って**から実行する
  （断って何もしない、をやめる）。選択が無ければメッシュ全体が対象になるので、
  これは Maya の Mesh > Merge と同じ意味になる
- 「中心にマージ」は頂点の選択が要る（今までどおり断る）

## T2. 輪が画面からはみ出るのを直す

### 何が起きていたか

`50` で横の寄せを**やめた**。輪を丸ごと画面へ入れようと横へ寄せると、押した点と
中心が 100px 以上離れ、「見えている区画」と「引いた向き」が食い違って
**目で見た所を押しても選べなかった**からだ（「段が足せない」の正体）。

寄せをやめたので選べるようにはなったが、**左のツール列で押すと輪の左半分が
画面の外**へ出る。見えない区画は指で押せない。今度はこれが声になった。

### 決め — 縮めてから寄せる。向きは 1 通りに絞る

1. **まず輪を縮める**。押した点から画面の端までの余裕を見て、`RING_OUTER`（176）を
   そこへ収まる大きさへ落とす。下限は **0.62 倍**（外 109 / 内 35）。
   これより小さいと文字が入らない
2. **それでも入らない分だけ寄せる**。縮めたあとの寄せは多くて 70px 程度で、
   `50` の 157px より遥かに小さい
3. **向きは常に輪の中心から読む**。`50` の「押した点から読む」と「輪の帯の上なら
   中心から読む」の 2 本立てをやめ、**見えている通り**の 1 本にする

   ```ts
   sel = toRing < dead ? -1 : sliceAt(ax, ay);   // ax, ay は輪の中心から
   ```

   ビューポートの 2 本指・3 本指は画面の真ん中で開くので寄せは 0、
   つまり中心 = 押した点。**見ないで振り抜く使い方はそのまま効く**（`41` の T3）。
   寄せが出るのは端のボタンだけで、そこは元々**見てから押す**場所

### 付け足し

- 輪の下の一覧も、幅が画面を超えるなら縮める
- 当たりの内外・一覧の行も、縮めた寸法で測る（固定の 176 / 56 / 42 を使わない）

## T3. 左側を指で押しやすく

Apple の目安は 44×44pt。今の左側はどれも足りない。

| もの | 今 | これから |
|---|---|---|
| ツールのアイコン `.ibtn` | 40×36 | **46×42**（当たりは `::before` で 56×48） |
| ツール列の間 | 3px | 6px |
| ツール列のドック | 63px | 71px |
| ゲージ `.gauge` | 幅 36px | **幅 46px** |
| 左レール | 64px | 74px |
| Undo / Redo `.bigbtn` | 52×44 | **58×48** |

  角の印は `::after` を使っているので空いている方を使う
- ビューポートは 18px 狭くなる。1024px の iPad で 5% ほど。押せない UI よりはよい

## 報告（実装のあと）

### T1. 変形の長押しにマージを入れた

- 輪の **NW = 「距離でマージ」**（`Merge 0.050`）。しきい値を副題に出しているので、
  押す前に何が溶けるか分かる
- そこに居た「初期設定に戻す」は一覧へ。一覧は **「中心にマージ」/「初期設定に戻す」**
  の 2 行で、**モードで切らない**
- `doMergeByDistance()` は頂点モードでなければ**自分で頂点モードへ入る**。
  選択は空にするのでメッシュ全体が対象になる（Maya の Mesh > Merge と同じ）
- `SW` のターゲットウェルドはそのまま

### T2. 輪が画面からはみ出るのを直した

- **縮めてから寄せる**。押した点から端までの余裕で `RING_OUTER` を落とす（下限 0.62 倍）
- **向きは常に輪の中心から読む**。`50` の 2 本立て（押した点 / 帯の上）をやめた
- 一覧の幅も画面に合わせて縮める

実測（1280×800、`dist`）:

| 押した所 | 前 | 今 |
|---|---|---|
| ツール列（変形） | 輪の左端 **−86px**・外径 176 | 左端 **+6px**・外径 109（寄せ 11px） |
| 筆の輪（左端） | 左端 −86px | 左端 **+6px** |
| 削除ボタン（左下） | 左 −4px | 左 **+14px**・右 366px |

#### 足した安全弁 — 「置いたまま離す」で走らない

削除の輪は一覧のぶん**下から 147px せり上がる**ので、開いた時点で指が
**南（オブジェクトを削除）の上**に居る。そのまま離すと消えてしまう。

- **開いた時に指が乗っていた区画は、そこから一度出るまで選ばない**。
  ハブに入る・別の区画へ移る、のどちらかで解ける
- 20px ぶれて離しても何も起きないことを通し確認で見ている

- 通し確認（`dist` と `app/`）に **4 件**足し、`41` / `50` の輪の検査 3 件を
