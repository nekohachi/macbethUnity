## T1. サークルメニューが選べない（いちばん大きい）

### 何が起きていたか

**2 つ重なっていた。**

1. **輪の中心を指からずらしていた。** 画面に丸ごと収めるため、ツール列（画面の左端）で
   押すと中心が右へ 98px 寄る。ところが**選ぶ向きは押した点からしか測っていなかった**
   （`41` の T3）ので、**目で見た区画に指を乗せても、そこは選ばれない**。
   一覧の行も同じで、見えている行に指を置いても届かなかった
2. **長押しの途中で指が 12px 動くと、長押しそのものを取り消していた。**
   指で押すと必ずぶれるので輪が出ず、離すと**タップ**（段を 1 つ上げるだけ）になる。
   これが「段が足せない」の正体

### 直し

- **横には寄せない。** 中心は押した点のまま。画面から出そうな**文字だけ**を内側へ寄せる
  （`clampText`）。これで「見えている区画」と「引いた向き」が**常に一致**する
- 縦だけは一覧が画面に収まるよう寄せる（縦のずれは北と南の読みを変えない）
- 選び方は 2 段構え。**指が輪の帯に乗っていれば見たまま**、輪の外なら**押した点から
  引いた向き**（見ないで振り抜く使い方）。真ん中（ハブ）はキャンセル
- **長押し中に指が動いても消さない。** ツール列のボタンは `touch-action: none` で
  スクロールに使わないので、消す理由がない。24px 以上引いたら 200ms を待たずに開く

`41` の「輪は丸ごと画面の中」という約束は、**「文字が全部読める」**に置き換えた。

## T2. SHF は指のオービットのまま

`47` の T4 で「モデリングの SHF + 空白ドラッグ = 矩形選択」にしたが、
**指でカメラを回せなくなるほうが痛い**。戻した。矩形選択は **F**（`24` の T2）。
SHF のカメラ吸着がスカルプトだけなのは変えない（`47` の声のまま）。

## T3. 削除ボタン（ALT の下）

- クラスターは **F / SHF / CTL / ALT / DEL** の 5 つになった
- **タップ** = いまのモードの削除
  （オブジェクト / 面を消して穴 / 辺を消して面を結合 / 頂点を消して 1 枚に）
- **長押し** = 輪で選ぶ

| 方位 | 中身 |
|---|---|
| N | 削除（Delete） |
| E | **コントロール削除**（Maya の Ctrl + Delete = Delete Edge/Vertex） |
| S | オブジェクトを削除 |

**コントロール削除**は、辺を消したあとに残る「辺 2 本の通過点」を面の角から外す。
そのために core へ `removeCorners` を足した。**形が変わる外し方はしない**
（板の角のような「辺 2 本だが本物の角」は残す。外してよいのは両側が内側の辺か、
ほぼ一直線のとき）。

## T4. 修飾ボタンの長押しに「説明だけの輪」

押している本人にしか分からなかったので、長押し中に輪を出す。

| 方位 | 見せるもの |
|---|---|
| N | `SHF 効いています`（ロック中 / 押している間だけ） |
| W | `ロック` ← 左へずらして離す |
| E | `解除` このまま離す → |

**選ばせる輪ではない。** `pointer-events: none` なので、指はこの下の 3D へ素通りする
（押しながら反対の手で触れる）。左へずらすと「ロック」が光る。
前の「← ロック」の札は輪に置き換えて消した。
