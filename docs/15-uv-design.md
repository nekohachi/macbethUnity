# 15. UV モードの設計（非破壊の自動展開）

作成: 設計担当（Fable）。ユーザーとの相談（2026-09-08）の結論。
実装担当（Opus）への作業は `16-opus-task-04.md`。`12` の Phase C はこの文書で置き換える。

---

## 0. 相談の結論

ユーザーの要望は 3 つ。

1. **自動で「いい感じ」に開いてほしい**
2. **非破壊**にしたい。自動の結果に人が切れ目を足し引きしたら、それを元に再計算
3. **全部手でやる道**も要る

判断:

| 問い | 結論 |
|---|---|
| 今の技術で自動は「いい感じ」になるか | **ハードサーフェスなら 7〜8 割まで届く。** 切れ目は経験則（角度、ハードエッジ、クリース、ポリグループ、対称）で置き、展開は決定的なソルバー（LSCM）で開く。人物・生物は自動を出発点にして人が切れ目を直す。機械学習の切れ目予測は、ライセンスが通り iPad で動くものが無いので v1 では使わず、**差し替えられる部品の穴だけ空けておく** |
| 非破壊にできるか | **できる。UV そのものではなく「UV の作り方」（レシピ）を保存する。** 切れ目・ピン・ソルバー・パッキングの設定から UV を再計算し、人が手で動かした分は差分として上に乗せる。マルチ解像度（`03`）と同じ「決定的な土台 + 差分」の形 |
| 全部手で | レシピの切れ目を空にして、ソルバーを「投影」にすれば、今のマニュアル UV と同じ。手で動かした差分がそのまま UV になる |

推奨として出した 3 点は、そのまま採用:

- 自動 UV は**押した瞬間に採用して開く**。気に入らなければ切れ目を直す（非破壊なので直せる）
- 手で動かした差分は**島（シェル）単位で残し、切れ目が変わった島だけ捨てる**
- v1 のソルバーは **LSCM**。差し替えられる形にしておき、C4 で ABF++ / SLIM を検討

**参考にしたもの:** 操作の割り当てと名前は Maya の UV エディタ。個々の便利機能は「CG自習部屋 Mayaの時間」（Ari 氏の AriUV 系 MEL）の**機能の考え方だけ**を取り込む（格子状の整列、直線化と比率合わせ、テクセル密度の数値表示と統一、UV セットの切替）。**コードは参照しない**（`01` のライセンス方針）。

## 1. 前提（変えないこと）

`11` の 6 章と `12` の Phase C で決めたことはそのまま。

- **独立した UV モード。** タブは「モデリング / UV / スカルプト / マテリアル」のまま
- **データは `mesh.uvSets["map1"]`（コーナー単位）。** ソルバーが最後にここへ書く。描画・保存・書き出しは今までどおりこれを見る
- **画面は 2D ビューと 3D ビューを並べ、選択を同期する。** 横持ちは左右、縦持ちは上下。上段に「片方だけ」の切替
- **ジェスチャは 3D と同じ。** 1 本 = ツール、2 本 = パン / ズーム、3 本 = 選択の操作、長押し = サークルメニュー。しきい値も同じ
- **ゲージの意味は固定。** 強度 = UV ソフト選択の強度、範囲 = UV 空間での半径
- **core は DOM にも Three.js にも触れない。** ソルバー、切れ目、パッキングは全部 `src/core/uv/` に置き、vitest で確かめる

## 2. 非破壊の構造: UvRecipe

### 2.1 何を保存するか

```
UvRecipe（SceneObject.uv に 1 つ。.mbz に保存）
  seams   : Set<エッジ（頂点の組）>        切れ目。自動が最初に置き、人が足す / 消す
  pins    : Map<コーナー, [u, v]>         固定する UV。ソルバーはここを動かさない
  method  : "lscm" | "projection" | "none" ソルバー。"none" は差分だけで UV を作る（全部手動）
  packing : { margin, allowRotate, texelDensity }
  manual  : Map<島の指紋, Map<コーナー, [du, dv]>>  手で動かした差分。島ごと
  autoSeamParams : { angle, useHardEdges, useCreases, usePolygroups, symmetric }
```

- **コーナー**は `(面, 面内の位置)`。`mesh.uvSets` と同じ単位なので、そのまま書ける
- **島の指紋**は「その島に含まれる面の集合のハッシュ + その島の境界にある切れ目の集合のハッシュ」。切れ目を変えると指紋が変わるので、その島の `manual` だけが無効になる。**これが「島単位で残し、切れ目が変わった島だけ捨てる」の実装**

### 2.2 再計算の流れ

```
recompute(mesh, recipe) → mesh.uvSets["map1"]

  1. charts  = 切れ目でメッシュを島に分ける（面の連結成分。切れ目の辺は越えない）
  2. 各 chart を展開:
       lscm       … 三角形分割して LSCM。ピンが 2 つ未満なら、最も離れた 2 頂点を自動で固定
       projection … 島の平均法線に垂直な平面へ投影
       none       … 前回の UV をそのまま（差分だけが効く）
  3. pack    = 島を 0〜1 に並べる。テクセル密度をそろえてから棚詰め
  4. 各 chart の指紋が manual にあれば、その差分を足す
  5. 結果を mesh.uvSets["map1"] へ書く
```

**決定的であること。** 同じ mesh と recipe からは必ず同じ UV が出る（並び順、丸めまで）。vitest で 2 回計算して一致を見る。

### 2.3 人の編集はどこへ入るか

| 操作 | recipe への反映 |
|---|---|
| カット / ソー | `seams` に足す / 消す → recompute |
| ピン / ピン解除 | `pins` → recompute |
| 島を移動 / 回転 / スケール | `manual[指紋]` に差分として記録（島の全コーナーに同じ差分）。recompute は走らない |
| UV 頂点を手で動かす | `manual[指紋]` にそのコーナーの差分 |
| 直線化、整列、格子化、反転 | 結果と現在の差を `manual[指紋]` へ。**中身は「手で動かした」と同じ扱い** |
| 自動 UV | `seams` を経験則で作り直し、`manual` を全部捨て、recompute |
| 展開（Unfold） | recompute だけ（切れ目はそのまま。手で崩した島を戻したいときに使う） |

「手で動かした分は差分」なので、切れ目を変えて recompute しても、**変わっていない島の手直しは残る**。

### 2.4 トポロジが変わったとき

モデリングモードでループ挿入や押し出しをすると頂点番号が変わる。`11` の表のとおり UV は「ループ挿入は補間で保持、それ以外は要再展開」。recipe 側はこう扱う。

- `seams` は頂点の組で持っている。**トポロジ操作の後、両端の頂点がまだ存在してその辺が残っていれば、切れ目は残る。** 消えた辺の分だけ落ちる
- `manual` は島の指紋で持っている。面の集合が変われば指紋が変わるので、**変わった島の差分だけ落ちる**
- `pins` はコーナー単位なので、面が変わったものは落ちる
- 全部落ちるのではなく、直した所だけ直し直せばよい状態にする。これが目標

`SceneObject.markTopologyChanged()` がすでにあるので、そこで `reconcile(recipe, mesh)` を呼ぶ。

## 3. ソルバー

### 3.1 LSCM（v1）

Lévy らの Least Squares Conformal Maps。三角形ごとに「角度を保つ」条件を最小二乗で解く。

- 入力は島の三角形（n-gon は解くときだけ三角形分割。結果は元のコーナーに書く）
- 未知数は各頂点の (u, v)。ピン 2 点を固定して、残りを疎な線形系で解く
- 解くのは**共役勾配法**（`12` で決めたとおり外部依存なし）。正規方程式 AᵀA x = Aᵀb を CG で。収束は相対残差 1e-6 か 2000 反復
- ピンが無い島は、島の中で最も離れた 2 頂点を (0,0) と (1,0) に置く。これで回転と拡大が決まる
- 島が 1 三角形でも 1 面でも解ける（投影と同じ結果になる）

**歪みの評価**を core に置く: 三角形ごとの伸び（3D の辺の長さと UV の辺の長さの比）と角度の差。C4 のヒートマップとテストの合格判定に使う。

### 3.2 投影（全部手動の土台）

島の平均法線に垂直な平面へ落とす。Maya の「平面マッピング（最適な平面）」と同じ。切れ目を全部手で引いた人が「まず平らに落として、あとは手で」と進める道。

### 3.3 差し替え口

`unwrapChart(chart, method, pins)` の中で分岐する。ABF++ / SLIM は C4 で同じ口に足す。ML の切れ目予測が来たら `autoSeams()` の実装を差し替えるだけ。

## 4. 自動の切れ目（C2）

経験則を 4 つ重ねて、最後にチャートを育てる。

| 規則 | 内容 | 既定 |
|---|---|---|
| 角度 | 二面角が閾値を超えるエッジを切れ目にする | 65° |
| ハードエッジ | スムージング角度でハードになっているエッジ | オン |
| クリース | `mesh.crease` が付いているエッジ | オン |
| ポリグループ | `mesh.polygroup` が違う面の境界 | オン |
| 対称 | 対称編集 X がオンなら、切れ目も X で鏡映して揃える | 対称 X に連動 |

そのあと **チャートの育成**（xatlas と同じ考え方。MIT だが今回は自前）:

1. 上の規則で分けた島のうち、大きすぎる島（面数が全体の 1/3 を超える、または法線のばらつきが 120° を超える）を見つける
2. その島の中で、法線が最も離れた 2 面を種にして領域を育て、境目に切れ目を足す
3. 閉じた島（球のように切れ目が輪にならない）は、必ず少なくとも 1 本の切れ目を通す。**そうしないと LSCM が解けない**（平らにできない）

結果は `seams` に入るだけ。ユーザーは 2D / 3D で切れ目を見て、要らないものを消し、足りないものを足す。

**「いい感じ」の判定:** 歪みの評価（3.1）で、島の最大伸びが 1.5 倍を超えたら、その島の中で切れ目を 1 本足す候補を出す（C4 の「提案」）。v1 では数字を HUD に出すだけでよい。

## 5. パッキング（C3）

- **テクセル密度をそろえる**（AriUVScaleChecker の考え方）。島ごとに「3D の面積 / UV の面積」を出し、指定の密度に合わせてスケールする。オプションで「密度を数値で指定」「選んだ島に合わせる」
- **棚詰め**（shelf packing）。島の境界箱を高さ順に並べ、行ごとに詰める。90° 回転を許す（オプション）。余白は UV 空間の 1/128 が既定
- 0〜1 に収まらなければ全体を縮める。UDIM は v1 では扱わない
- xatlas の wasm 化は **Phase E のツールチェーンができてから**。それまでは自前の棚詰めで足りる

## 6. 画面と操作

### 6.1 画面

`12` の Phase C のまま。

- 横持ち: 左に 2D UV ビュー、右に 3D ビュー。境目をドラッグで動かせる
- 縦持ち: 上に 2D、下に 3D
- 上段に **「2D / 両方 / 3D」の 3 択**
- 2D ビューは平行投影、0〜1 の枠と**チェッカー**（8×8。オプションで 16×16、32×32）。枠の外もグレーの格子を出す
- 3D ビューにもチェッカーを貼れる（表示切替に「チェッカー」を足す。モデリングモードでも使える。`11` の「モデリング側に置くもの」）

### 6.2 選択

| 単位 | 何を選ぶか | 2D | 3D |
|---|---|---|---|
| UV 頂点 | コーナー。同じ位置に重なった UV は 1 つとして扱う | ○ | ○（3D 頂点をタップ → その頂点の全コーナー） |
| UV エッジ | 面の辺（切れ目なら 2 本に見える） | ○ | ○ |
| UV シェル | 島 | ○（タップで島ごと） | ○（面をタップ → その面の島） |

同期の単位は面。2D で選ぶと 3D の対応面が光り、3D で面を選んで UV モードに入ると、その島が選ばれている。

マーキングメニュー（指 1 本長押し）は 8 方位そのまま、中身を UV 用に:

| 方位 | 項目 |
|---|---|
| 北 | UV エッジ |
| 北東 | オブジェクト（3D 側の選択へ戻る） |
| 東 | **UV シェル** |
| 南東 | （空き） |
| 南 | 面（3D と同期） |
| 南西 | （空き） |
| 西 | UV 頂点 |
| 北西 | 選択を拡張（CTL で縮小） |

### 6.3 編集メニュー（指 2 本長押し / SHF + 長押し / Shift + 右クリック）

Maya の UV エディタの右クリックメニューに合わせる。単位ごとに中身を差し替える。

**シェル:**

| 方位 | 項目 | 中身 |
|---|---|---|
| 北 | 展開 | Unfold。recompute |
| 北東 | 自動 UV | 経験則で切れ目を作り直して展開 |
| 東 | 整列 | 島の並べ直し（パッキング） |
| 南東 | 反転 U | |
| 南 | 反転 V | |
| 南西 | 90° 回転 | |
| 西 | テクセル密度をそろえる | AriUVScaleChecker の考え方。数値はオプション |
| 北西 | 直線化（境界） | Maya の Straighten UV Border |

**エッジ:**

| 方位 | 項目 | 中身 |
|---|---|---|
| 北 | カット | `seams` に足す |
| 北東 | ソー | `seams` から消す。Maya の Sew |
| 東 | 移動してソー | Move and Sew。小さい方の島を寄せてから縫う |
| 南東 | 直線化 | 選んだエッジ列を直線に（AriUVRatio の考え方） |
| 南 | 整列 U | 選んだエッジの U を平均にそろえる |
| 南西 | 整列 V | |
| 西 | 格子化 | AriUVGridding。四角形の帯を格子に整列 |
| 北西 | ループ選択 | エッジループ（3D の規則と同じ） |

**頂点:**

| 方位 | 項目 | 中身 |
|---|---|---|
| 北 | ピン | `pins` に入れる |
| 北東 | ピン解除 | |
| 東 | 整列 U | 選んだ頂点の U をそろえる（Maya の Align Min/Max/Center。既定は中心） |
| 南東 | 整列 V | |
| 南 | マージ | 重なった UV 頂点を 1 つに（距離はオプション） |
| 南西 | 分離 | |
| 西 | 直線化 | 頂点列を直線に |
| 北西 | 対称 | 対称 X の相手へ UV を写す |

### 6.4 指の操作（今までの流れのまま）

| 操作 | 効果 |
|---|---|
| 1 本（島の上） | 選択 / ツイーク。ドラッグで UV を動かす（差分として記録） |
| 1 本（外） | 何もしない（2D にタンブルは無い） |
| 2 本 | パン / ズーム |
| 2 本ダブルタップ | 戻る |
| 3 本 つまむ | 選択のスケール（基点は選択の中心） |
| 3 本 上下スワイプ | V に沿って移動 |
| 3 本 左右スワイプ | U に沿って移動 |
| 3 本ダブルタップ | 進む |
| 3 本長押し | カメラメニュー（3D 側。2D では「0〜1 にフレーム」「選択にフレーム」の 2 択） |
| F | 選択にフレーム。押しながらドラッグで矩形選択 |
| CTL | スナップ（グリッド 1/8、1/16、1/32 / UV 頂点） |

マニピュレータは 3D と同じものを 2D に置く（矢印 2 本、リング 1 本、箱）。ピボットは選択の境界箱の中心。

### 6.5 オプションパネル（UV モード）

| 区画 | 中身 |
|---|---|
| 自動 UV | 角度閾値、ハードエッジ / クリース / ポリグループを使う、対称 |
| 展開 | ソルバー（LSCM / 投影 / なし）、歪みの数値（最大伸び、平均角度差） |
| パッキング | 余白、90° 回転を許す、テクセル密度（数値と「選択に合わせる」） |
| 表示 | チェッカーの細かさ、歪みのヒートマップ（C4） |
| スナップ | グリッドの刻み（1/8 …）、UV 頂点 |
| UV セット | 一覧と切替（AriUVSetList）。v1 は `map1` だけでもよいが、切替の口は先に作る |

## 8. 合格条件（core。vitest）

| # | 内容 | 合格 |
|---|---|---|
| U1 | 立方体に十字の切れ目（7 本）を入れて LSCM | 6 枚の面すべてで角度差 < 1e-3、伸び 1.00±1e-3（平面なので厳密に開ける） |
| U2 | 円柱（上下を落とした筒）に縦 1 本の切れ目 | 長方形に開く。最大伸び < 1.02 |
| U3 | 同じ mesh と recipe で 2 回 recompute | UV が完全一致（決定的） |
| U4 | 島 A を手で動かし、島 B の切れ目を変えて recompute | A の差分は残り、B の差分は消える |
| U5 | 立方体に自動の切れ目（角度 65°） | 各島が平面（島内の法線のばらつき < 1e-6） |
| U6 | 球（プリミティブ）に自動の切れ目 | すべての島が LSCM で解ける（閉じた島が無い）。最大伸び < 2.0 |
| U7 | パッキング | 全島が 0〜1 の中。境界箱どうしが重ならない。余白以上離れている |
| U8 | ループ挿入のあと reconcile | 残っている辺の切れ目は残り、無くなった辺の分だけ落ちる |
| U9 | テクセル密度をそろえる | 島ごとの「3D 面積 / UV 面積」の比が 1% 以内でそろう |

通し確認（Chromium）は `16` の指示書に書く。
