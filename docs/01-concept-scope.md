# 01. コンセプトとスコープ

## 1.1 一行で言うと

**「Maya のポリゴン編集精度を持った、タブレット完結型スカルプト＆テクスチャリング環境」**

## 1.2 なぜ勝てるのか（差別化の核）

タブレット向け 3D アプリはすでに競合がいます。正直に整理します。

| アプリ | 強み | 弱み（＝我々の入る隙間） |
|---|---|---|
| Nomad Sculpt | 軽い、スカルプトが優秀、完成度が高い | ポリゴンモデリングが弱い。エッジループ、ベベル、UV 編集が実質ない |
| ZBrush for iPad | ZBrush 互換のスカルプト | サブスクリプション。モデリング/UV は ZBrush 流で Maya 系ではない |
| Forger (Maxon) | 軽量スカルプト＋簡易ポリ編集 | UV、マテリアルが弱い |
| Shapr3D | CAD としては完成度が高い | ポリゴンモデリング用途ではない |
| Substance Painter | 業界標準テクスチャリング | モバイル版が存在しない |

**空いている席は「タブレットで Maya 相当のポリゴンモデリングができる」ところです。**
そして、ご要望の以下の機能はどの競合も持っていません。

> ディバイドスライダーを下げてモデリングモードで頂点編集すると、ハイモデルの形状を保ったままローモデルを調整できる

これはマルチ解像度編集（multiresolution editing）と呼ばれるもので、ZBrush は「サブディビジョンレベル」として持っていますが、**低レベルで Maya 相当のポリゴン編集ツール（エッジループ挿入、ベベル、ブリッジ）を使わせてくれません**。ここが本アプリの唯一無二の売りになります。

したがって **v1 の最優先実装はマルチ解像度ブリッジ** です。UI やマテリアルより先に、ここの技術検証を通してください。詳細は `03-multires-core.md`。

## 1.3 スコープの現実的な線引き

率直に申し上げると、ご提示いただいた全機能（モデリング＋UV＋スカルプト＋マテリアル＋将来アニメーション）は、**Substance Painter だけで数十人年、Nomad Sculpt は個人開発で 5 年以上**かかっている規模です。全部同時に着手すると確実に頓挫します。

推奨する優先順位:

1. **必須（v1.0）** — スカルプト、ポリゴンモデリング、マルチ解像度ブリッジ、入出力（OBJ / FBX / USD）
2. **重要（v1.5）** — UV モード、スカルプトレイヤー、ベイク
3. **後回し（v2.0）** — マテリアルモード
4. **将来（v3.0）** — アニメーションモード

マテリアルモードは今回「作らない」とのご指示どおり、`05-modes.md` に設計方針だけ残します。判断としても正しいです。理由は `06-file-formats.md` の Substance の項に書いたとおり、**Substance のファイル形式は法的・技術的に読めない**ため、ここに突っ込むと時間を溶かします。

## 1.4 想定ターゲット端末と性能ライン

「なるべく軽く動作する」を数値化しておきます。ここを曖昧にすると際限なく重くなります。

| 指標 | iPad Pro (M系) | 中位 Android タブレット |
|---|---|---|
| スカルプト対象ポリゴン数 | 800万トライアングル | 150万トライアングル |
| ストローク中のフレームレート | 120fps（ProMotion） | 60fps |
| アプリ使用メモリ上限 | 3.0GB | 1.2GB |
| 起動からモデル表示まで | 3秒以内 | 5秒以内 |
| ペン入力から描画までの遅延 | 30ms 以下 | 50ms 以下 |

Android は端末の幅が広く、メモリ不足によるプロセス強制終了が最大のクラッシュ要因になります。**メモリ予算を設計段階から固定し、超えたら自動でサブディビジョンレベルを落とす**仕組みを入れてください。

## 1.5 「PC でも動く」の位置づけ

PC 対応は「移植」ではなく「入力プロファイルの差し替え」として設計します。同一コードベースで、入力層だけを切り替えます。

- タブレット: ペン＝ツール、指＝カメラ
- PC: マウス＝ツール、Alt＋マウス＝カメラ（Maya 準拠）、ペンタブレット接続時はタブレットと同じ筆圧処理

PC 版を「おまけ」と割り切るのではなく、**開発マシン上で動く PC 版があると開発速度が桁で変わります**。実機ビルドを待たずにイテレーションできるためです。初日から PC ビルドを維持することを強く推奨します。
