## T1. 3 本指のひねりで回転

### ユーザーの要望（原文の要点）

> 手を捻って回転させる。時計 / 反時計まわりで、カメラ方向から見て X / Y / Z 軸を判断。**必ずカメラ方向に対して垂直の軸**。手の回す向きと合うように。**5° ずつ**回る。今何度回っているかを**カットインで表示**。**絶対にフリー軸で回転しない**。使う指は親指・中指・薬（または人差し）指。親指と残り 2 本のあいだに**空間が生まれる**のが特徴。

### 決め

| | |
|---|---|
| 何が起きるか | 3 本指を置いて**ひねる**と、選択（オブジェクトまたはコンポーネント）が**ピボットのまわりで回る**。つまむ = 拡大縮小、スワイプ = 移動と並ぶ 3 つめの 3 本指の中身 |
| 軸（ALT なし） | **カメラの視線にいちばん近いワールド軸**（X / Y / Z のどれか 1 本）。前ビューなら Z、上ビューなら Y、既定のパースなら Z。トラックボールのような自由軸は**やらない** |
| 向き | 画面で**時計まわりにひねれば、画面でも時計まわりに回る**。軸がカメラの手前を向いているか奥を向いているかで符号を返す（`transform.ts` の `updateDrag` の回転と同じ考え方） |
| 刻み | **5°**。生の角度は連続で積み、当てるのは `round(raw / 5°) * 5°`。表示も刻んだ値 |
| 表示 | 指の重心の少し上に**小さなカットイン**（`.twist-pop`）。中身は「**Z +15°**」の 1 行（軸と符号つきの角度）。HUD のヒントにも「回転 `Z +15°` · 指 3 本」 |
| 確定 | 指が 1 本でも離れたら確定して履歴に 1 段（「回転」）。今の 3 本指と同じ |
| ソフト選択・対称 | 今の 3 本指の変形と同じ経路（`applyGestureTransform`）なので、そのまま効く |

### 判定（`input/gestures.ts`）

今の 3 本指は `spreadMotion`（つまみ）と重心の移動（スワイプ）を **同じ 10px の物差し**で比べて、大きい方に決めて以後は変えない。ここに**回転**を 3 つめとして足す。

**回転の測り方は、指ごとの角度差の平均（`rotationSince`）を使わない。** 親指と残り 2 本のあいだに空間があるので、重心は 2 本のほうに寄り、2 本の指は重心に近すぎて角度がぶれる。代わりに**親指 → 2 本の中点**を結ぶ 1 本のてこで測る:

1. 3 本のうち、**他の 2 本からいちばん離れているもの**を「親指」とする（各指について「他の指までの距離の最小値」を出し、それが最大のもの）
2. 残り 2 本の中点を「対」とする
3. てこ = 対 − 親指。**てこの角度（`atan2`）の開始時からの差**が回転量。画面の座標は y が下なので、`atan2` が増える向き = 画面の時計まわり
4. 親指がどの指かは**開始時点（`basis`）で決めて、以後は変えない**

判定の物差し（すべて px。開始時点からの量）:

- `pinch = spreadMotion(basis, now)`（今のまま）
- `swipe = |重心の移動|`（今のまま）
- `turn = |てこの角度差| × (てこの長さ / 2)`（対の中点が描く弧の長さ。`clusterMotion` が 2 本指でやっているのと同じ換算）

どれかが `CLUSTER_DEADZONE`（10px）を越えた時点で**いちばん大きいものに決める**。回転に決めるにはさらに 2 つ:

- **てこの角度差 ≥ 5°**（刻み 1 つ分。曲がったスワイプを回転に取らない）
- **親指と対のあいだに空間がある**: `|親指 − 対の中点| ≥ 1.4 × |対の 2 本の距離|`。ユーザーの言う「空間が生まれる」を判定に使う。3 本が均等に開いていると（パンをしようとして指を広げたとき）回転には入らない → つまみかスワイプに落ちる

この 2 つを満たさなければ、`turn` が最大でも**回転にはせず、次に大きいもの**（つまみかスワイプ）にする。どれも 10px に届かなければ今までどおり何もしない。

**1.4 は実機で確かめる値。** 中指 + 薬指はくっつくので実際は 2 以上になるはず。きつすぎて回転に入らないなら 1.2 まで下げてよい。1.0 にすると条件が消える。値は `gestures.ts` の先頭の定数にまとめ、コメントに「実機で確かめる」と書く。

`GestureDelta` に足す:

```ts
| { kind: "rotate"; /** 画面の時計まわりが正。ラジアン。刻む前の生の値 */ radians: number; axis: "vertical" | "horizontal" }
```

`axis` は T3 の ALT が使う（`Cluster.axis` をそのまま。つまみと同じ決め方）。回転に決めた時点で `g.basis = now` にし直して飛びを防ぐのも、つまみ・スワイプと同じ。

### 適用（`app.ts` と `tools/transform.ts`）

- `applyGestureTransform(drag, object, t)` の `t` に `rotate?: { axis: Vector3; angle: number }` を足す。中身は `updateDrag` の回転と同じ（`apply` に `rotation: Quaternion` を渡し、頂点はピボットのまわりで回す）。**scale / move / rotate は同時には来ない**（ジェスチャが 1 つに決まっているため）
- `app.ts` の `updateGestureTransform`:
  1. 軸を決める（ALT なし）: カメラの forward（`camera.getWorldDirection`）と X / Y / Z の `|dot|` がいちばん大きいもの。**ジェスチャの開始時に 1 回決めて、途中で変えない**（`gestureView` に持つ。`horizontal` と同じ扱い）
  2. 符号: 画面の時計まわり θ に対して、軸がカメラの**手前**を向いているとき（`axis · (camera − pivot) > 0`）は世界での回転を `−θ`、奥を向いているときは `+θ`。これで**手の向きと画面の回り方が一致する**。書いたら必ず通し確認で「上の頂点が右へ動く」ことを見る（下の通し確認 1）
  3. 刻み: `snapped = round(θ / 5°) × 5°`。0° のうちは何もしない（表示は「Z 0°」）
  4. `note = 回転 <kbd>Z +15°</kbd>`
- カットイン `.twist-pop`: `document.body` に置く `position: fixed` の小さな札。左上は指の重心の上 56px。開始時に作り、`transformUpdate` のたびに文字を入れ替え、`transformEnd` で消す。目の不透明度の `.opacity-pop` と同じ作り（当たり判定なし）。文字は「Z +15°」を 13px のモノスペースで、軸を薄く・角度を濃く

### 通し確認（1 項目）

「3 本指のひねりで回転（5° 刻み、軸は視線に垂直）」: 前ビュー（平行投影）に立方体。親指を重心の左下 70px、対を右上に 2 本（間隔 14px）に置く → 3 本を重心のまわりで**時計まわりに 32°** 回す（10 段で）→ `.twist-pop` の文字に「Z」と「30°」がある → 離す → `transform.scale` は `[1,1,1]` のまま、`position` も動いていない → `rotation` が **Z まわり 30°**（`|角度 − 30°| < 0.5°`）→ **画面で時計まわりに回っている**: 立方体の上面の中心（ローカル `(0, .5, 0)`）を投影した x が、回す前より**右**にある → 履歴の最後が「回転」→ 取り消しで戻る。

PNG: `26-t1-twist.png`（回している最中。カットインが出ている）。

## T2. ひねりと平行移動・拡大縮小を取り違えない

T1 の判定が正しく分かれることを、**通し確認として独立に持つ**。実装は T1 に含まれる。

### 通し確認（1 項目）

「3 本指のひねり・スワイプ・つまみを取り違えない」。前ビューの立方体で 4 つ:

1. **曲がったスワイプは移動**: 3 本を右へ 60px 動かしながら、各点を重心のまわりで 3° だけ回す（人の手はまっすぐ動かない）→ `position` が動き、`rotation` は単位のまま
2. **つまみは拡大縮小**: 親指と対を離す向きに 40px 開く → `scale` が 1 より大きく、`rotation` は単位のまま
3. **均等に開いた 3 本を回しても回転に入らない**: 正三角形（辺 60px）に置いて 30° 回す → `rotation` は単位のまま。`position` も `scale` も変わらない（どれも 10px に届かない）
4. **ひねりはつまみに化けない**: T1 と同じ置き方で回すとき、回している途中で対の 2 本の間隔が 14 → 18px に開いても（指は少しずれる）`scale` は `[1,1,1]` のまま

## T3. ALT + ひねりで手前 / 奥へ回す

### ユーザーの要望

> ALT キーを押しながらだと、カメラ方向に対して X / Y / Z 軸を基準に手前・奥へ回転する。

### 決め

ALT が効いているとき（クラスターのラッチ `state.modOn("alt")`。`25` の T2 と同じで、PC の Alt キーはジェスチャ中に取れないのでラッチだけ）、軸を**視線に垂直な軸**から**画面の面に沿った軸**に変える。どちらの軸かは **つまみの ALT と同じ規則**（`Cluster.axis`）で決める。規則を 1 つにして覚える量を増やさない:

| 指の並び（いちばん離れた 2 本） | 軸 | 動き |
|---|---|---|
| 縦 | **画面の横に沿ったワールド軸**（X か Z。カメラの右向きに近いほう） | 上が手前に倒れる / 奥に倒れる |
| 横 | **Y** | 左右に首を振る |

向き: 縦の並びで**時計まわりにひねる = 上が手前に来る**（画面の右側が下がる回り方と一致）。横の並びで時計まわり = 画面の右側が奥へ行く。ここも符号は通し確認で確かめる。

刻みとカットインは T1 と同じ。カットインの軸の文字が X / Y / Z のどれかに変わるだけ。

### 通し確認（1 項目）

「ALT + ひねりで手前 / 奥へ回る」: 前ビュー、`mods.alt = "on"` → 縦に並べて（親指が下、対が上）30° ひねる → `rotation` が **X まわり**で `|角度| = 30°`、上面の中心を投影した **y が下へ動く**（手前に倒れると上面が見えてくる = 画面では下へ）→ 戻す → 横に並べて 30° → **Y まわり** 30° → `mods.alt = "off"` にして同じ置き方で回すと **Z まわり**（T1 の動き）。

## T4. アトリビュート欄の置き場所をドラッグで選ぶ

### ユーザーの要望

> アウトライナの上にアトリビュートタブを常に出して、クリックして可変するのは使いづらい。ドッキング箇所をアウトライナの下か上かはドラッグで選べるように。

### 決め

- **折りたたみ（`<details>`）をやめる。** トランスフォーム / 表示 / 入力ノードは**いつも開いている**。「メッシュ」の区画はやめて、末尾に 1 行のヒント（頂点 · エッジ · 面）にする。`fold()` と `attrFold` の記憶は消す
- 欄の高さは**ドロワーの 50% を上限**にして中でスクロール（`max-height: 50%; overflow-y: auto`）。一覧がつぶれないように
- 欄の見出し（`.attr-head`）の左端に**つまみ**（`.attrgrip`。アウトライナの行の `.lygrip` と同じ 6 つの点）。**つまみを掴んで上下に運ぶ**と、欄が一覧の**上か下か**に移る。判定は「離した位置がドロワーの縦の中央より上か下か」。運んでいる間は欄を半透明にして、落ちる側に細い線（`--accent`）を出す
- 置き場所は `localStorage` の `macbeth.attrDock`（`"top"` / `"bottom"`）。既定は `"top"`（今と同じ）
- 見出しのダブルタップで名前変更（`25` の T3）はそのまま。つまみは名前変更と当たらない位置（左端）

ドラッグは `attachOutlinerGrip` と同じ書き方（購読は `window`、`setPointerCapture` は try / catch）。**欄は描き直しで入れ替わる**ので、掴んだ要素ではなくドロワーの矩形で判定する。

### app

- `panels.ts` の `attributeSection(state, host)`（`opened` を消す）。`.attr-head` に `.attrgrip`、`PanelHost` に `onAttrDock(side: "top" | "bottom")`
- `app.ts` の `renderPanels`: `attrDock` に応じて `.attrs` を `.lylist` の前か後ろに置く。ドロワーの本体を `display: flex; flex-direction: column` にして、`.lylist` を `flex: 1 1 auto; overflow-y: auto`、`.attrs` を `flex: 0 0 auto; max-height: 50%`
- `shell.css`: `.attrs` の `margin: -8px -8px 8px` は上に置く前提の値なので、`.attrs[data-dock="bottom"]` のときは `margin: 8px -8px -8px` に（境界線も上に）
- `remember("attrDock", side)` と `restoreSettings` での読み戻し

### 通し確認（1 項目）

「アトリビュート欄を一覧の下へ運べる」: ドロワーを開く → `.attrs` が `.lylist` の**前**にある → `.attrs details` が **0 個**（折りたたみが無い）→ `.attrgrip` を掴んでドロワーの下端近くまで運んで離す → `.lylist` が `.attrs` の前にある → `localStorage` の `macbeth.attrDock === "bottom"` → もう一度上へ運ぶ → 元に戻り `"top"`。

PNG: `26-t4-attrs-bottom.png`（欄を下に置いたところ）。

## 決めてあること（追加分）

- 3 本指の中身は **つまみ / スワイプ / ひねり の 3 つ**。始まった時点で 1 つに決まり、途中で入れ替わらない（今までの規則を守る）
- 回転の軸は**必ずワールド軸 1 本**。ALT なしは視線に近い軸、ALT ありは画面の面に沿った軸。自由軸は無い
- 回転量は**親指 → 2 本の中点のてこ**で測る。指ごとの角度の平均は使わない
- 刻みは 5° で固定（変形の刻み `rotateStep` とは別。あちらはマニピュレータ用）
- アトリビュート欄は折りたたまない。上か下かだけ選べる

## やらないこと

- 3 本指の自由軸（トラックボール）回転
- ひねりと同時のつまみ・スワイプ（複合ジェスチャ）
- 刻みの変更 UI（必要になったら変形のカットインに足す）
- アトリビュート欄をドロワーの外へ出す（フローティング）
