## そのあと（`28` の順）

**S3 は `49` で本当に終わり（`46` + マテリアル表示）。E 書き出しは `48`。** 「スカルプト → 焼く → Substance / Blender」は
**ファイル 1 つ（.zip）で回る**ようになった。次の候補は 3 つ:

1. **v2.0 のマテリアル**（`31`。塗り。テクスチャセット × チャンネル × レイヤー）。`49` がその手前の 1 段
2. **読み込み側**（glTF / FBX。`28` の E の残り。外から持ってくる道）
3. **B11 の 3 択**（`46` の宿題。実機の数字が要る）

**S2-4 は `42`、S2-5 は `43`、S3-1 は `44`、S3-2 は `46` で終わり。**
wasm への移し替えと描画のインデックス化は、100 万四角形を触るときか、
実機の B2a が 100ms を超えたときに戻す。
