## T1. カットインに「今の傾き」と「動かした量」

ユーザー: 「カットインの角度は現在の傾き度と傾き量の二つを表示して」。

- 大きい数字が**今その軸で何度傾いているか**、右の小さい数字（アクセント色）が**この操作で何度動かしたか**。`Z 50° +20°` のように出る
- HUD のヒントにも同じ 2 つ（`回転 Z 50° +20°`）
- 今の傾きは**スイング・ツイスト分解**で出す（`tools/transform.ts` の `tiltAbout`）。クォータニオンのうち、その軸に平行な成分だけを取り出して角度に直す。返すのは −180〜180
- 符号は札の中で揃えてある。画面で時計まわりが正なので、軸がカメラの手前を向いていれば世界の回転とは逆になる
- **コンポーネント（頂点 / エッジ / 面）を回すときは「今の傾き」が無い**ので、動かした量だけを大きく出す。頂点の集まりに「今の傾き」は定義できないため

## T2. 分割線のドラッグ

- `Viewport.split = { x, y }`（0〜1 の比）。`paneRect` がこれを見る。2 分割は片方だけ、4 分割は両方
- 分割線のつまみは枠の中に置いた `.panesplit`。**枠（`.paneframe`）は当たり判定を持たないが、この線だけは指を受ける**。幅 11px（指で掴める太さ）
- 端に寄せすぎるとペインが潰れるので **0.15〜0.85 で止める**
- 動かすと枠ごと描き直されるので、購読は `window` に置いて掴んだ要素が消えても追いかける（アウトライナのつまみと同じ作り）
- 比は `.mbz` と自動保存に残る（`doc.layout.split`）

## T3. 選択したものだけ表示

Maya の Isolate Select。**ペインごと**に効く。

- `Pane.isolate: Set<string> | null`。null なら全部見せる
- 入口は**シェードのカットイン**の「選択したものだけ」。今のペイン（最後に触れたペイン）に効く。何も選んでいなければトーストで断る
- 枠の名前が「パース · 選択だけ」になる。分割していないときは枠が出ないので、トーストとチェックの状態で分かる
- 描画のたびにペインごとに `group.visible` を当てる（真偽値の代入だけなので毎フレームでも軽い）。**表示の付け替え（材質）はキャッシュしているが、こちらは必ず通す**
- **隠れているものは選べない**。`picker.pickSurface` が入力を受けているペインの隔離を見る。見えていないものを拾うと、選択が飛んだように見えるため
- `.mbz` には入れない（作業中の都合。`camOpts.locked` と同じ扱い）

## T4. 透けているものの前後関係

`25` の T4 で不透明度を入れたとき、`depthWrite: false` で誤魔化していたところ。

- 透けているオブジェクトは**「裏面 → 表面」の 2 回に分けて描く**。裏面だけの複製（`ObjectView.back`、`renderOrder = -1`）を先に描く。1 回で描くと同じオブジェクトの裏の面が表より後に来ることがあり、内側の形が手前に浮いて見える
- 裏面の材質は表の材質の複製（`backMaterial`）。チェッカーやヒートマップでも同じ絵になる。表の材質が入れ替わったら作り直す
- **「裏面を描かない」がオンのときは出さない**（そもそも裏面を捨てているので 2 回描く意味が無い）
- ジオメトリは `surface` と同じものを指す。作り直しのたびにそろえる

### やっていないこと

**透けたオブジェクトどうしの厳密な前後**は three.js の距離順に任せている。裏面のぶんをまとめて先に描くので、透明なものが 2 つ重なると理屈の上では順が崩れる（B の裏 → A の裏 → B の表 → A の表）。1 つのオブジェクトの中は正しくなり、実用で困るのはここまでのはず。困ったら深度で分ける方式に変える。
