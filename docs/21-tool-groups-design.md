# 21. ツール列をグループにする（長押しで選ぶ、タップでオプション）

作成: 設計担当（Fable）。2026-09-08。T1〜T3 をタブレットで触ったユーザーの指示をまとめたもの。
`19` の 3.2（オプション → ツールのカットイン）を**置き換える**。指示書は `20` の T8。

---

## 0. 結論

ツール列のボタンは **1 つ = 1 グループ**。どのボタンも同じ 3 つの規則で動く。

| 操作 | 何が起きるか |
|---|---|
| **長押し** | サークルメニュー。グループの中身から 1 つ選ぶ（ツールならそれになる。コマンドなら実行する） |
| **タップ** | **今そのグループで選ばれているもの**のオプションが、ボタンの横からカットイン。ツールのグループなら、そのツールが有効でなければ有効にもする |
| **アイコン** | 今そのグループで選ばれているもののアイコンになる（動的に切り替わる） |

ユーザーの言葉のまま: 「基本ツールバーは長押しサークルメニュー、シングルタップで現在選択されているオプションがカットイン」。

これでツール列は **7 つ**になる（今は 17）。右の「オプション」パネルは無くなる。

```
選択    ← オブジェクト / 頂点 / エッジ / フェース
変形    ← ユニバーサル / 移動 / 回転 / スケール（+ ピボット編集）
編集    ← マルチカット / ベベル / ブリッジ / …
スナップ ← グリッド / 頂点 / カーブ / サーフェス / オフ
表示    ← シェーディング
カメラ  ← パース / 正面 / 上 / … / 新規カメラ / 控えたカメラ
追加    ← 立方体 / 球 / 円柱 / …
```

## 1. 規則の細部

### 1.1 タップ

- カットインは `.cutin.wide`（幅 236px、`19` の 3.2 と同じ）。ボタンの右に出る。縦持ちも同じ（ツール列は左のまま）
- **閉じる**: 外を触る、同じボタン、別のボタン、ツールを変える（マーキングメニューで選択モードを変えたときも）
- ツールのグループ（選択 / 変形 / 編集）は、タップでそのグループの今の中身が**有効になる**。マルチカット中に「変形」をタップ → 移動ツールに戻り、移動のオプションが出る。有効にするのとカットインは同時（2 段階にしない。理由: 2 段階だと「今どっちの段か」を覚える必要がある。カットインは外を触れば消えるので、出ても邪魔にならない）
- コマンドのグループ（追加 / カメラ / 表示 / スナップ）は、タップで**実行しない**。オプションが出るだけ。実行は長押しのメニューから。例外は **スナップ**: タップ = オン / オフ（`17` の 7 章の決めのまま）。オプションはカットインに移すが、タップの意味は変えない（磁石のボタンは「押したら効く」が自然）
- （`24` の T5 で追記）もう 1 つの例外は UV 列の **カット / ソー**（`cutsew`）: タップ = 最後に使ったものを**実行**。オプションを持たず、毎回使うコマンドだから。長押しで カット / 移動して縫う / その場で縫う

### 1.2 長押し

- サークルメニューは今の `attachRadialButton` のまま（`radial.ts`。ハンドルの向きは変えない）
- 選ぶと**アイコンが変わり**、タップの中身も変わる。マニピュレータの「ユニバーサル / 移動 / 回転 / スケール」は今の `manipMenu` そのもの
- メニューの中身に「未実装」を入れない。無いものは載せない（`STUBS` の予定表はモードだけ）

### 1.3 アイコン

- `ToolEntry` に `icon: () => string`（関数）を許す。描き直しは `renderToolColumn()` で済む（今も `syncToggleButtons` がそれを呼んでいる）
- ボタンの右下に小さな三角（`▸`）を付けて「長押しで中身がある」ことを示す。今 `data-radial` のボタンに付いているものがあればそれ

## 2. グループごとの中身

### 2.1 選択（選択モード）

| | |
|---|---|
| 中身（長押し） | 北 オブジェクト / 東 頂点 / 南 エッジ / 西 フェース。**頂点フェース**は北東に置くが、**このタスクでは載せない**（コーナー単位の選択データが無い。法線 / マテリアルで要るときに足す） |
| アイコン | 今の選択モード（`COMP_ICONS`） |
| タップ | 選択ツールになり（`setTool("select")`）、選択のオプションがカットイン |
| オプション | **カメラベース選択**（オン / オフ、既定オフ = 今の挙動）、ソフト選択（強度 / 範囲。今の区画）、プリセレクション ハイライト（オン / オフ）、頂点マージ距離・押し出し幅（今の「頂点」区画。頂点モードのときだけ）、押し出し距離とミラー軸（今の「押し出し」「ミラー」区画。エッジ / フェースのときだけ） |

**カメラベース選択**（Maya の Camera based selection）: オンのとき、**カメラから見えている**頂点 / エッジ / 面だけを選ぶ。裏側は選ばない。今は裏の頂点もタップ・矩形で拾える。

決め: `picking.ts` の `pickVertex` / `pickEdge` と、`select.ts` の矩形選択に**遮蔽の判定**を足す。判定は「その頂点の画面位置で `pickSurface` を撃ち、当たった面までの距離が頂点までの距離より **0.5% 以上**近ければ隠れている」。面は「面の中心」で同じ判定。矩形選択は頂点数ぶん撃つので、4 万頂点で 1 秒を超えるなら `raycaster` ではなく深度バッファ（`WebGLRenderTarget` に深度だけ描いて読む）に切り替える。**最初は raycaster で作り、通し確認で時間を測って報告する**。

### 2.2 変形（マニピュレータ）

| | |
|---|---|
| 中身（長押し） | 北 ユニバーサル / 東 移動 / 南 回転 / 西 スケール（今の `manipMenu`）+ **北東 ピボット編集**（D。トグル）+ **南東 ピボットをリセット** |
| アイコン | 今の `manip`（`xform` / `move` / `rotate` / `scale`）。ピボット編集中は `pivot` |
| タップ | 選択ツールになり（マルチカット中でも戻る）、今のマニピュレータのオプションがカットイン |
| オプション（共通） | マニピュレータの大きさ（**今の縦ゲージをそのまま中に置く**。`openManipSizeGauge` の中身を移す）、ピボット編集（トグル）、軸 = ワールド / オブジェクト |
| 移動 | 上の共通だけ。**UV を保つ**（Maya の Preserve UVs）は core の仕事なので**後で** |
| 回転 | 刻み（オフ / 5° / 15° / 45° / 90°。ドラッグ中の角度をこれに丸める） |
| スケール | **負のスケールを防ぐ**（オン / オフ、既定オン。ドラッグで 0 を跨がせない: 元の 0.001 倍で止める）、一様（中心のハンドルでの一様スケール。今の挙動の名前付け） |

「マニピュレータ」のボタン（今のツール列 4 番目）はこのグループに吸収される。**ボタンとしては消える**。

### 2.3 編集（変形系のコマンドとツール）

ユーザー: 「何をまとめるかは後で考える」。ここでは**案を 1 つ決めて作る**。あとで入れ替えられるように、グループの定義は配列 1 つで持つ（3 章）。

| | |
|---|---|
| 中身（長押し） | 北 マルチカット / 東 ベベル / 南 ブリッジ / 西 押し出し（`extrude`。マーキングメニューと同じ）/ 北西 コネクト / 南西 ターゲット ウェルド（頂点モードのとき） |
| アイコン | **最後に使ったもの**（既定はマルチカット） |
| タップ | 最後に使ったものが**ツール**（マルチカット / ベベル）ならそれになり、オプションがカットイン。**コマンド**（ブリッジ / 押し出し / コネクト / ウェルド）なら実行はせず、そのオプションだけ出す |
| オプション | マルチカット（刻み・エッジフロー。今の区画）、ベベル（幅・分割。今の区画）、押し出し（距離）、ブリッジ（分割数 = 今は 1。スライダーを足すが、core が分割を受けなければ 1 固定で「後で」と表示） |

### 2.4 スナップ

今のまま（タップ = オン / オフ、長押し = 種類）。**アイコンは今の種類**（グリッド / 頂点 / カーブ / サーフェス。オフのときは薄く）。オプション（刻み、サーフェスのとき「自分を除く」）は右のパネルから**カットインへ移す**が、出し方は**長押しメニューの「オプション…」（南）**にする。理由: タップの意味を変えない。

### 2.5 表示（シェーディング）

| | |
|---|---|
| 中身（長押し） | 今の `shadingMenu`（ワイヤ / シェード / シェード + ワイヤ / スムース） |
| アイコン | 今の `display` |
| タップ | 表示のオプションがカットイン: スムージング角度（今の「表示」区画）、裏面を描かない、グリッド表示 |

今の「タップで切り替え（4〜7）」は長押しに寄せる。キーの 4〜7 はそのまま。

### 2.6 カメラ

| | |
|---|---|
| 中身（長押し） | **`cameraMenu()` そのもの**（パース / 正面 / 上 / … / 新規カメラ）+ 輪の下に控えたカメラ（`savedCameraItems`）。指 2 本の長押し・指 3 本の長押しで出るものと**同じ関数を使う** |
| アイコン | `camera`。正投影のときは薄い枠を足す |
| タップ | 今の `openCameraPopup` の中身（焦点距離 / near / far / 正投影）をカットインに |

### 2.7 追加（プリミティブ）

| | |
|---|---|
| 中身（長押し） | 8 種を 8 方位に（`PRIMITIVE_ORDER` の順で北から時計回り）。選ぶと**原点に追加**（今の `addPrimitive`） |
| アイコン | **今選んでいるオブジェクトがパラメトリックならその種類**、そうでなければ**最後に追加した種類**（既定は立方体） |
| タップ | **今選んでいるオブジェクトがパラメトリックなら、そのパラメータ**（今の「入力ノード」区画。履歴に積むのも今のまま）。そうでなければ、**最後に追加した種類の既定値**（次に追加するときの値。`state.primitiveDefaults[kind]` に持ち、`addPrimitive` がそれを使う）。見出しでどちらか分かるようにする（「Cube1 の入力」/「次の立方体」） |

「入力ノード」と「メッシュ」の区画は `19` の 3.3 でレイヤーの行へ移す予定だったが、**ここに置く**（ユーザー指示）。レイヤーの行（T9）にはトランスフォームの数値と表示 / ロックだけ残す。

## 3. 実装の形（Opus 向けの骨格）

`app.ts` の `toolColumn()` を「グループの配列」に置き換える。

```ts
interface ToolGroup {
  id: "select" | "xform" | "edit" | "snap" | "display" | "camera" | "add";
  title: string;
  /** 今の中身のアイコン。 */
  icon: () => string;
  /** 押されて見せるか（ツールが有効、スナップがオン、ピボット編集中）。 */
  pressed?: () => boolean;
  /** 長押し。無ければ長押しは何もしない。 */
  radial?: () => RadialMenu;
  /** タップ。ツールを有効にしてからカットインを開く、など。 */
  onTap: (button: HTMLElement) => void;
  /** カットインの中身。null なら出さない。 */
  options: () => HTMLElement | null;
}
```

- `openToolOptions(anchor, group)`: `openManipSizeGauge` と同じ骨格（`.cutin`、`closePopup` で消える、`popup.dataset.gauge = group.id`）。同じグループをもう一度タップで閉じる
- `panels.ts` の `renderOptions` を**区画ごとの関数**に分ける（`packingSection` と同じ形）: `selectSection`, `softSelectSection`, `xformSection(manip)`, `multicutSection`, `bevelSection`, `extrudeSection`, `snapSection`, `displaySection`, `cameraSection`, `primitiveSection(object | kind)`。`renderOptions` 自体は消す
- **UV モードのツール列**は `17` の 2.4 のまま（選択 3 / 展開 / カット / ソー / マニピュレータ / スナップ / フレーム）。ただし**同じ規則を当てる**: 「選択」を 1 グループ（UV 頂点 / エッジ / シェル）に、「マニピュレータ」は 2.2 と共通、「スナップ」は 2.4 と共通。展開 / カット / ソー / フレームはコマンドのボタンのまま（毎回使うので 1 タップで実行）。展開のタップは実行、**長押しで展開のオプション**（方式 / 自動 UV / パッキング。`20` の T7）
- `state.ts` に足すもの: `cameraBased: boolean`（既定 false）、`rotateStep: number`（既定 0）、`preventNegativeScale: boolean`（既定 true）、`lastEdit: "multicut" | "bevel" | "bridge" | "extrude" | "connect" | "weld"`、`lastPrimitive: string`、`primitiveDefaults: Record<string, PrimitiveParams>`。`localStorage` に残すのは `cameraBased` / `rotateStep` / `preventNegativeScale` / `lastPrimitive`
- 右の「オプション」パネル（`zones.options`、`optionsBody`）は消す。**ドッキングの右上ゾーンは残す**（T9 で PC の「レイヤー」の置き場）

## 4. 合格条件（触って分かること）

1. ツール列のボタンが 7 つ。右のオプションパネルが無い
2. 「変形」を長押し → 回転を選ぶ → アイコンが回転になる → タップ → 回転の刻みが出る → 15° にする → ドラッグで 15° ずつ回る
3. マルチカット中に「変形」をタップ → 移動ツールに戻り、移動のオプションが出る
4. 「追加」を長押し → 球 → 球が増えてアイコンが球になる → タップ → 「Sphere1 の入力」で分割数が動かせる → 何も選ばずにタップ → 「次の球」の既定値
5. 「カメラ」を長押し → 上ビュー → タップ → 焦点距離が出る
6. 「選択」をタップ → カメラベース選択をオン → 裏の頂点が矩形で選ばれない（立方体で手前の 4 点だけ）
7. 「スケール」でドラッグして 0 を跨ごうとしても裏返らない（オプションを切ると裏返る）

通し確認は 1〜7 をそのまま項目にする（7 つ）。

## 5. やらないこと

- 頂点フェースの選択（データが無い。法線 / マテリアルのときに）
- 移動の「UV を保つ」（core。UV のフェーズの後）
- ブリッジの分割数（core が受けるまで 1 固定）
- ツール列の並び替え・カスタマイズ（グループの中身はコードの配列 1 つで持つので、後で入れ替えは簡単）
- サークルメニューの見た目の変更（`radial.ts` は触らない）
