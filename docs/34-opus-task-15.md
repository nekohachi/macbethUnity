## 1. 何を作るか

`05` の「マスキング」から、v1.5 に要る分:

| 入れる | 理由 |
|---|---|
| **ペンで描くマスク**（CTL ラッチ中のストローク） | ZBrush の Ctrl+ドラッグ。彫らない所を決める基本 |
| **消す**（CTL + ALT） | 描き過ぎを戻す |
| **ぼかし / 反転 / 全解除** | 境目をなじませる、逆側を彫る、やり直す。この 3 つが無いとマスクは使い物にならない |
| **裏面マスク** | **これが無いと薄い形が破綻する**（`05`）。ムーブで耳を引くと反対側の耳まで動く |
| **Shift で一時スムース** | `04` の表。ZBrush の Shift と同じ。マスクと同じ「修飾で役割が変わる」仕組みに乗せる |

入れないもの（S2-4 以降）: ポリグループ単位、キャビティ、モデリングの選択面から
マスク（`05` の 19 行目）、マスクの形を残したまま段を跨いで細部を保つこと。

### 決めの要点

- **マスクは頂点ごとの 0〜1。** 0 = 彫れる、1 = 彫れない。ブラシの重みに `(1 - mask)` を掛けるだけ
- **1 つの段にだけ持つ**（`o.mask = { level, values }`）。段を変えたら**移す**（4 章）。
  ZBrush も段ごとに持っているが、v1.5 では 1 段で十分。下へ移して上へ戻すと
  細部が消えることは受け入れる（ぼかしで直る程度）
- **無いときは `null`。** 掛け算も色も要らない。マスクを使わない人に 1 バイトも
  払わせない
- **裏面マスクは既定でオン。** ZBrush の既定はオフだが、タブレットで薄い形を
  触るときに切り忘れて壊すほうが痛い
- **ストロークの役割は押した瞬間に決めて、離すまで変えない。** 途中で CTL を
  切っても、そのストロークはマスクのまま

## T1. core のマスク

### `src/core/mask.ts`（新規）

`src/core/sculpt.ts` と同じ作法。**`Mesh` と `Float32Array` を触るだけ。**
マルチ解像度も履歴も描画も知らない。

```ts
/** マスクを 1 回当てる。values を書き換え、実際に変わった頂点を返す。 */
export function paintMask(
  mesh: Mesh, fp: Footprint, values: Float32Array,
  input: { point, radius, strength, erase: boolean, excludeNearX? },
): Uint32Array;

/** 1 リングの平均へ寄せる。全頂点。 */
export function blurMask(mesh: Mesh, tri: Uint32Array, values: Float32Array): void;

/** 1 - v。全頂点。 */
export function invertMask(values: Float32Array): void;

/** 1 つ上の段へ移す（線形）。下の段のメッシュとその値を渡す。 */
export function maskUp(below: Mesh, values: Float32Array): Float32Array;

/** 1 つ下の段へ移す。上の段の値の先頭 V_below 個をそのまま。 */
export function maskDown(values: Float32Array, belowVertexCount: number): Float32Array;
```

#### 塗る

`applyStroke` の Standard と同じ骨格。`strokeFootprint` で範囲を取り、
`falloff(d / radius) * strength` を **足す**（`erase` なら引く）。0〜1 に切る。
値が変わった頂点だけ返す（履歴と部分描画に渡すので、`applyStroke` と同じ約束）。

1 打ちの濃さは `DAB_DEPTH` と同じ考えで、**打つ間隔（半径の 1/4）と対**にする。
強さ 1 で 1 なぞりすると 1 に届く程度（1 打ち 0.125 × 8 打ち）。既定の強さ 0.67
なら 1 なぞりで 0.67 になり、重ねれば 1 になる。

対称のときの中心線（`33` の T4 の `excludeNearX`）はそのまま効かせる。

#### ぼかす

三角形の辺を使って、隣の平均へ寄せる。`localAverages` と同じ「辺を両向きに足す」
やり方で、**全頂点を 1 回**。読みながら書かない（先に全部読む）。
1 回で 1 リングぶん。ボタンを押すたびに広がる。

#### 段を移す

細分割の出力の並びは **頂点点 `[0, V)` → エッジ点 `[V, V+E)` → 面点 `[V+E, ...)`**
（`subdivide.ts` の 121 行目）。wasm 版も同じ並び（`subdiv-wasm.test.ts` で
1 ビットも違わないことを見ている）。

- **上へ**: 頂点点はそのまま、エッジ点は両端の平均、面点は角の平均。
  `below.edges()` と `below.faceVerts(f)` の並びは `SubdivPlan` が使うものと
  同じなので、**`SubdivPlan` を作らずに済む**（作ると 25 万で数秒かかる）
- **下へ**: 先頭 `V_below` 個を切り出すだけ

Catmull-Clark の重みは使わない。マスクは柔らかい場なので線形で足りる。

### `src/core/sculpt.ts` に足す

`StrokeInput` に 2 つ:

```ts
/** 頂点ごとのマスク（0〜1）。あれば重みに (1 - mask) を掛ける。 */
mask?: Float32Array;
/**
 * 裏面マスク。視線の向き（オブジェクト空間、カメラから面へ）。
 * あれば、法線がこれと同じ向きを向いている（= 裏を向いている）頂点を触らない。
 */
viewDir?: readonly [number, number, number];
```

- **マスク**: `weights[i] *= 1 - mask[v]`。重み 0 になった頂点は動かさないし返さない
  （`applyStroke` の約束どおり）
- **裏面**: `localNormals` は Standard しか作っていない。`viewDir` があれば
  Move と Smooth でも作り、`n · viewDir > 0` の頂点は重み 0。
  **法線は範囲の三角形から作るので、追加の重さは範囲の大きさぶんだけ**
  （メッシュ全体には触らない。`sculpt.ts` の前提を守る）

### テスト（`tests/mask.test.ts`）

- 塗る: 中心がいちばん濃く、半径の外は 0 のまま、1 を超えない、`erase` で戻る、
  変わった頂点だけ返す
- ぼかす: 1 点だけ 1 の場が、1 回で隣へ広がる。0〜1 を出ない。10 回掛けても
  合計（総量）がほぼ保たれる
- 反転: 2 回で元に戻る
- 段を移す: `maskDown(maskUp(m)) === m`（先頭が頂点点なので必ず戻る）。
  上げたエッジ点は両端の平均になっている
- `applyStroke` にマスク 1 を渡すと**1 ミリも動かない**。0.5 なら半分
- 裏面: 球に `viewDir` を渡して当てると、**裏側の頂点は動かない**。渡さなければ
  裏も動く（今までどおり）。Move と Smooth でも同じ
- **裏面マスクの重さ**: `viewDir` の有無で `applyStroke` の時間が 2 倍を超えない
  （範囲の法線 1 回ぶん）

## T2. データと保存

### `SceneObject`

```ts
/** マスク（`34`）。無ければ null。1 つの段にだけ持つ。 */
mask: { level: number; values: Float32Array } | null = null;
```

- `markTopologyChanged()` で **捨てる**（段と同じ扱い。頂点の数が変わるので持てない）。
  戻り値に `droppedMask: boolean` を足して、トーストで言う
- `clone()` があれば複製する

### `.mbz`

- `mask/<id>.bin`（f32）と JSON に `maskLevel`。無ければ `null`
- `MBZ_FORMAT_VERSION` は **1 のまま**。無いファイルを無いと読むだけなので、
  古い読み手を壊さない（`06` の「必ず版を入れる」は、壊すときに上げるため）
- `tests/io.test.ts` に往復を 1 つ

### 段を変えたとき（`app.ts` の `goLevel`）

`o.mask` があって `o.mask.level !== 次の段` なら、**1 段ずつ** `maskUp` / `maskDown`
で移す。`levelsOf(o).level(i)` で各段のメッシュが取れる。

- 段を足したとき（`addLevel`）は今の段のまま（新しい段へは行かないなら移さない。
  行くなら `goLevel` が移す）
- 段を捨てたとき（`dropAboveLevel`）: マスクの段が残る段より上なら、残る段へ下ろす
- 焼き込んだとき（`burnDownLevel`）: マスクの段も `at` だけ引く。0 未満になるなら
  捨てる（レベル 0 に持てるが、モデリングでは使わないので）

**段を移すのは履歴に入れない**（段を変えること自体が履歴に入らないのと同じ）。
その代わり、履歴のマスクの差分は**段を憶えている**（T3）。

## T3. つなぐ

### ストロークの役割（`src/app/stroke.ts`）

`begin` で決める。**離すまで変えない。**

| 押した瞬間 | 役割 |
|---|---|
| CTL（ラッチ、または PC の Ctrl / ⌘） | **マスクを描く**。ALT も立っていれば**消す** |
| Shift（ラッチ、または PC の Shift） | **スムース**（ブラシの種類は変えない。このストロークだけ） |
| どちらも無し | 今のブラシで彫る（ALT で反転。今までどおり） |

`Live` に `role: "sculpt" | "mask"` と `kind: BrushKind`（Shift のときは `"smooth"`）を持つ。
`stamp` と `hit` は `role` で分岐する:

- `sculpt`: 今までどおり。ただし `StrokeInput` に `mask: o.mask?.values`
  （段が同じときだけ。違うときは T2 の移し替えが済んでいるはずなので同じ）と、
  裏面マスクがオンなら `viewDir` を渡す
- `mask`: `o.mask` が無ければ**その段で作る**（全部 0）。`paintMask` で書く。
  `flush` は `viewport.refreshMask(o, verts)`（下）を呼ぶ。段のデルタは触らない

**`viewDir` の作り方**: `hitLocal` と同じ変換で、カメラの向き（`camera.getWorldDirection`）
をオブジェクト空間へ回す（**平行移動は掛けない**。`matrixWorld` の回転だけ。
スケールが入るなら正規化）。ストロークの間は動かないので `begin` で 1 回作る。

**筆圧**: マスクにも効かせる（半径と強度、`brushAt` そのまま）。

### 履歴（`src/app/history.ts`）

`Entry` に `mask` を足す:

```ts
interface MaskDiff {
  ref: SceneObject;
  /** マスクがあった段。 */
  level: number;
  verts: Uint32Array;
  /** verts.length。 */
  before: Float32Array;
  after: Float32Array;
  /** 全解除など「無かった / 無くなった」の前後。 */
  wasNull: boolean;
  isNull: boolean;
}
```

- 描く: `beginMask` / `trackMask` / `commitPending` を `sculpt` と同じ形で。
  控えるのは **初めて触ったときの値**（同じ頂点を何度なぞっても「ストロークの前」）
- ぼかし / 反転: `verts` = 全部、前後を全部持つ（4 バイト × V。25 万で 1MB。十分軽い）
- 全解除: `isNull = true`、`before` = 全部、`after` = 空
- **当てるとき**（`applyDiff`）: `o.mask` の段が `diff.level` と違えば、まず
  `o.activeLevel = diff.level` にして表示を組み直してから当てる（sculpt の
  差分は段ごとにデルタがあるのでそれで済むが、マスクは 1 段にしか無いので
  **その段へ行く**）。`onMaskUndo(o, verts | null)` で描画を直す

### 描画（`src/app/render/viewport.ts`）

- `ObjectView` に `masked?: MeshPhongMaterial`（`MAT.surf.clone()` に
  `vertexColors: true`）。`applyDisplay` で、**スカルプトモードで `o.mask` が
  あるとき**だけこれを使う（`faded` / `checker` / `heat` と同じ並びに置く。
  優先は `checker` > `heat` > `masked` > `faded` > `MAT.surf`。ヒートは UV の
  確認なので、そのときはマスクを見せなくてよい）
- `surface.geometry` の `color` 属性を、頂点ごとに `1 - 0.65 × mask` の灰色で
  埋める（ZBrush の暗い灰色）。属性は `slots.surfaceSlots` で頂点 → コーナーに
  展開する（`refreshMoved` と同じ表）
- `refreshMask(o, verts)`: 動いた頂点のぶんだけ `color` を書き換える
  （`refreshMoved` と同じ形。`needsUpdate` だけ）
- `refreshMaskAll(o)`: ぼかし / 反転 / 解除 / 段の移し替え / 読み込みのあと
- `rebuildObject` は `o.mask` があれば色も作る

**マスクが `null` になったら `masked` は使わない**（`MAT.surf` に戻る）。
色の属性は残っていてもよい（材質が見ないだけ）。

### ワイヤ・点

触らない。スカルプトではワイヤを出さない（`33` の T4）ので、色を付ける先は面だけ。

## T4. メニューと言い訳

### ツール列（`sculptToolColumn`）

「筆」の下、「段」の上に **「マスク」** を 1 つ:

| 操作 | 動き |
|---|---|
| タップ | **CTL ラッチを入れる / 切る**（`state.mods.ctrl`）。修飾クラスタの CTL と同じもの。押されている見た目は `mods.ctrl !== "off"` |
| バッジ | `o.mask` があれば "M" |
| 長押し | 下の 8 方位 |

| 方位 | 項目 | 動き |
|---|---|---|
| N | ぼかし | `blurMask` 1 回。履歴 1 段 |
| E | 反転 | `invertMask`。履歴 1 段 |
| S | 全解除 | `o.mask = null`。履歴 1 段。無ければ何もしない（トースト「マスクはありません」） |
| W | 裏面マスク | `brush.backfaceMask` の入り切り。`sub` に「オン / オフ」。履歴に入れない |

`BrushState` に `backfaceMask: boolean`（既定 **true**）。

アイコンは `ICONS.mask` を 1 つ描く（24×24。半分塗った円など。既存の `sym` の
作法で）。

### 修飾の表示

修飾クラスタの CTL は今でも使える。マスクのボタンとクラスタの CTL は**同じ状態**を
指すので、片方を押せばもう片方も押された見た目になる（`syncModButtons` と
`renderToolColumn` の両方を呼ぶ）。

### 言い訳（`strokeHint`）

- CTL が立っているとき: 「マスクを描いています（ALT で消す）」
- Shift が立っているとき: 「スムース（Shift のあいだだけ）」
- 「段を足してから」などは今までどおり。**マスクを描くのも段が要る**
  （レベル 0 ではモデリングと同じ道になるので、v1.5 では描かせない）

### HUD

`hud.ts` のスカルプトの行に「マスク あり / なし」は**要らない**。バッジで足りる。

## T5. 門

### 数字

`?bench=1` の B6a を **CI で** 測り直す。マスクあり（`mask` を全部 0.3 で渡す）と
裏面マスクあり（`viewDir` を渡す）を足して、**どちらも B6a の 1.3 倍を超えない**こと。
ベンチの行にはしない（実機で見たいのは B6a のままなので、行を増やすと読みにくい）。
テストで見る（`tests/mask.test.ts` の重さの項目で足りるなら、そこで）。

### 通し確認（`scripts/smoke.mjs`）

`33` の項目の隣に足す。**終わったら必ずモードとマスクと修飾を戻す**（`33` で
3 回引っかかった。CTL ラッチを切り忘れると、後ろのモデリングの項目が全部
「選択から除外」になる）。

1. 段を 2 つ足し、CTL ラッチを入れてなぞる → `o.mask` ができて、なぞった所が
   0 より大きい。**材質が `masked`** で、`color` 属性がある
2. ラッチを切って同じ所を彫る → **マスクの濃い頂点は動かない**（動いた頂点の
   集合とマスク 1 の集合が交わらない）
3. 反転 → 値が `1 - v`。ぼかし → 分散が減る。全解除 → `null` で材質が `MAT.surf`
4. 取り消しを 3 回 → 順に戻る。やり直し → 順に進む。**履歴の段の数**が合う
5. 段を 1 つ下げる → マスクが残っていて頂点数が合う。上げる → 同じ
6. `.mbz` に書いて読む → マスクが戻る（段も）
7. Shift ラッチでなぞる → ブラシの種類は変わらないまま、スムースが掛かっている
   （ばらつきが減る）。離すと `state.brush.kind` は元のまま
8. 裏面マスク: 球の手前を Move で引く → 裏側の頂点が動かない。切ると動く
9. モデリングでトポロジを変える → マスクが消えてトーストに出る

PNG: `docs/img/34-mask.png`（マスクを描いた球。暗い所が見える）と
`docs/img/34-mask-menu.png`（長押しメニュー）。`scripts/shot.mjs` に足す。

### 実機で見てもらうこと（報告に書く）

1. CTL を入れてなぞると暗くなる。ALT で消せる
2. 暗い所は彫れない。ぼかしで境目がなじむ
3. **ムーブで耳を引いても反対側が動かない**（裏面マスク）。切ると動く
4. `?bench=1&size=25` の B6a（MovinkPad。門の条件で測り直し）

## 決めてあること

- マスクは頂点ごとの 0〜1、1 つの段にだけ持つ。段を変えたら線形で移す
- 無いときは `null`。掛け算も色も払わない
- 裏面マスクは既定でオン。法線は範囲の三角形から作る（メッシュ全体に触らない）
- ストロークの役割は押した瞬間に決めて離すまで変えない
- `src/core/mask.ts` は `Mesh` と `Float32Array` を触るだけ

## やらないこと

- ポリグループ・キャビティ・選択面からのマスク（S2-4 以降）
- マスクの段ごとの保持（v2）
- マスクの表示色の調整 UI
- 残りのブラシ、レイヤー、アルファ（S2-4）
- wasm（S2-5）
