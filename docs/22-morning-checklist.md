### 1.2 UV の手順（Maya と同じ流れになっているか）

**手順 A: 立方体**
1. 立方体 → UV モード。十字の展開図が見える
2. 3D で上の面を選ぶ → 2D でその島が光る
3. 長押しメニュー「カット」→ 2 島に分かれる
4. 「展開」→ 島がまっすぐ立ち、間が空く
5. UV エッジ単位で縁を 1 本タップ → **もう一度タップ（ダブルタップ）で縁が一周選ばれる**
6. 別の辺を **SHF + ダブルタップ**すると、その間だけ
7. 長押しメニュー「直線化」
8. 島を動かして**指 2 本ダブルタップ**で戻る
9. 頂点単位で**ダブルタップ → 島の全頂点**
10. 「整列」

**手順 B: 円柱**
1. 円柱（分割 12 × 高さ 3）→ 3D でエッジ、側面の縦の辺を**ダブルクリックでループ** → カット
2. 「展開」
3. UV エッジで帯の縁を選ぶ → 長押しメニュー **南西「境界の直線化」**
4. シェル単位で帯を選ぶ → 長押しメニュー **南西「格子化」** → 帯が長方形の格子になる
5. 「整列」

**手順 C: 球**
1. 球 → 3D で赤道のループを選んでカット → 上下 2 島
2. 「展開」
3. UV エッジで切れ目を選ぶ → **東「移動して縫う」（Move and Sew）** → 下の島が上に寄って縫われる
4. 頂点を矩形で選んで「対称」

## 2. 決めてほしいこと（急がないもの）

答えを待たずに進められるよう、**今は自分で決めて実装してあります**。触ってみて違ったら教えてください。

| # | 決めたこと | なぜ | 変えるなら |
|---|---|---|---|
| 1 | **SHF / CTL を押しているときは、フェースのダブルクリックでシェルに広げない** | 球で面を続けて選べなかった原因。細かいメッシュだと隣を叩くだけでダブルクリック扱いになる | 「SHF でもシェルが欲しい」なら別のジェスチャに割り当てます |
| 2 | **ダブルクリックは「同じコンポーネントを 2 回」でないと成立しない**（3D も 2D も） | 上と同じ理由。Maya もこの規則 | — |
| 3 | **分割数を変えると、切れ目・ピン・手の差分は捨てて、新しいメッシュの UV から引き直す**（方式・パッキング・自動の設定は残す） | 頂点の番号が全部変わるので、そのままでは別のところを指してしまう | 「分割を変える前の切れ目を、位置で近いものに引き継ぐ」ことは技術的には可能です（ただし当たり外れが出ます） |
| 4 | **「ソー」はエッジ / シェル単位では Move and Sew になった**（頂点単位は今までどおり） | Maya でも普段使うのはこちら | 別々のボタンに分けることもできます |
| 5 | **レイヤーの並び替えは履歴に積んでいない** | 表示の順だけで、メッシュにもレシピにも影響しないため | 積むこともできます |
| 6 | **シェルの編集メニューから「自動 UV」を外した**（「展開」の長押しへ）。空いた南東は 90° 回転 | T7 の指示どおり。8 方位が埋まっていたので入れ替えが必要だった | 並びの好みがあれば教えてください |
| 7 | **カメラベース選択は「面の向き」で判定**（遮蔽は見ない） | レイキャストだと球 3000 点で 964ms。面の向きなら 9ms。Maya の Camera based selection も向きで判定する | 「別のオブジェクトに隠れたものも外したい」なら、深度バッファを使う実装に切り替えます（重くなります） |
