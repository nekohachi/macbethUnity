UV エディタ

2D の UV ビューと 3D ビューを左右に並べ、片方の選択がもう片方に同期します。モデリングモードで面を選択すると、対応する UV シェルが選択された状態でこのモードに入ります。

  • 展開LSCM / ABF++ による対話的なアンフォールド自前実装
  • 自動 UVシーム自動生成とアトラス化xatlas
  • カット / ソーペンでシームを描いて切り開く、縫い合わせる自前実装
  • レイアウトシェルのパッキングと UDIM 1001–1010xatlas
  • 歪みの可視化チェッカーマップとヒートマップ表示自前実装
未実装 — v1.0 の中核

スカルプト

モデリングモードで作ったローモデルを、クリースとディバイドでハイメッシュ化します。ディバイドスライダーを下げてモデリングに戻り頂点を編集すると、ハイメッシュのディテールを保ったままローモデルを調整できます。左のゲージはそのまま「ブラシ強度」と「ブラシサイズ」に置き換わります。

  • ブラシStandard / Clay / Move / Smooth / Pinch / Inflate / Flatten / Trim / Polish11 種
  • サブディビジョン接空間デルタによるマルチ解像度スタックOpenSubdiv
  • マスキングペン描画、キャビティ、ポリグループ、裏面マスク自前実装
  • 対称X / Y / Z 軸対称と放射状対称自前実装
  • レイヤーレベルごとのデルタバッファと強度スライダーv1.5
未実装 — v2.0 予定

マテリアル

2D ビュー（UV 空間）と 3D ビューを同時に表示し、両方で同期してペイントします。Substance のファイル形式は非公開のため直接は読めません。書き出したテクスチャセットを命名規則で自動認識する方式で対応します。左のゲージは「不透明度」と「ブラシサイズ」に置き換わります。

  • チャンネルBaseColor / Roughness / Metallic / Normal / Height / AO / Emissive7 種
  • レイヤー塗り、ペイント、マスク、フォルダ、ブレンドモード自前実装
  • ベイク法線、AO、カーブチャ、厚み、ポジション、ID2K 既定
  • 読み込みテクスチャセット（PNG / TGA / EXR）と MaterialX.sbsar 不可
  • 書き出しテクスチャセット、glTF、MaterialX自前実装
